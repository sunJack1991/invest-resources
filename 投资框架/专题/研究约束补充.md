### 6.1 新买入许可

**研究前置条件（四支柱自检，依据B03导论）。** 任何新研究或复查在进入下列各门之前，先完成一次**四支柱自检**并留痕：①**理论**（用的是风险—回报关系，还是"这次不同"；是否把过去的高回报当成未来的高回报）；②**历史**（是否知悉同类资产的极端情形与幸存者偏差）；③**心理**（是否处于过度自信、过度交易或下跌中无法坚持的状态）；④**行业**（对手方靠什么赚钱、激励是否与我的长期收益一致）。**四支柱自检不通过的项写入"未知"**，并按本门规则处理——**不得用"估值便宜"替代自检**（依据B03导论："任一支柱有缺陷都会以残酷的方式击沉组合"）。

**对手方与费用结构核对（依据B03第9–10章）。** 任何新买入在进入下面各门之前，先完成一次对手方核对并留痕：

1. **对手方是谁、靠什么赚钱**（券商/平台/基金公司/顾问）：**是否有受托责任；报酬是否只来自我支付的费用**（不接受与销售挂钩的佣金、12b-1、load）；争议解决机制是什么。
2. **交易成本口径**：是否 principal transaction（价差而非佣金，**不得双重收费**）；**load 与 12b-1 一律为零**；冷僻标的的价差与冲击成本；**ETF 的机构稳定性（解散风险与资本利得）**。
3. **不适用"全方位服务"券商**；经纪人或销售渠道的推荐**不作为买入依据**。
4. **账户成本单独核算**：401(k)/403(b)/457 等的公开与隐含成本按年记录（参照：401(k) ≥2%、457 >3%）；与 IRA 滚存等替代路径对比。

**管理层与资本配置核对（依据B05开场白）。** 个股买入前，除财报与生存门外，另完成一次管理层核对并留痕：

1. **资本配置记录**：过去若干年留存利润的投向（再投资/并购/偿债/分红/回购）与各自结果；公司是否用“每股价值/股东回报”语言反思配置，而不只用规模与营收；能否给出“每留存1美元创造多少市值”的证据或反证。
2. **回购与增发纪律**：回购是否在低于保守价值时执行（高价回购、借债回购、为抵消期权稀释而回购不自动加分）；增发/以股并购是否在物有所值时进行。
3. **披露质量**：是否好坏兼报、是否避免“大洗澡”与数字平滑、是否给所有股东同时同等信息；把“持续提供盈利指引”“只报调整后口径”记为减分迹象（衔接§6.3媒体信息核查与手册§9）。
4. **激励与稀释**：期权/限制性股票是否与个人业绩和资本成本挂钩；无条件授予、行权重定价、仅以留存利润增长判定业绩的授予按“可能打劫股东”处理。
5. **控股与治理结构**：控制权、投票权、关联交易、质押、董事会构成与独立性；“管理层优秀”不是跳过价格门的理由。
6. **并购行为检查（依据B05第5章）**：近年的收购以现金还是发股支付；发股收购按**内在价值口径**的稀释/增值测算（不使用EPS口径）；支付价格对每股内在价值的影响；动机自检（规模、成长口号、童话叙事）。

**规模与机会成本核对（依据B05后记）。** 每次研究前记录两项：①**组合规模与单笔最小有效规模**——"资金太多是获得超级投资回报的敌人"，规模上升会缩小可选项；②**被放弃的机会**——没有符合标准的标的时，"不行动"是正式结论（作者以泰德·威廉姆斯的"幸运区"等待作比），须记录被放弃标的的名称、当时估值水平与放弃理由。

**边界**：本条不构成"长期空仓"的许可（战略配置仍按§3执行），也不改变§4.2压力测试与§5再平衡；"恐惧是朋友"仅作**研究触发条件**，不构成加仓授权。

**金融工具边界（依据B05第3章）。** 本项目不参与：新发行低等级信用债、零息/PIK结构证券、衍生品杠杆（含完全收益掉期）与外汇方向性头寸。持仓公司若含此类工具，按手册§9.6核对（降级-追加担保条款、累计利息、结算期风险）；“货币类资产”的通胀税（书中口径：维持购买力需约4.3%年化）进入现金管理评价，但不改变§4防御资产的许可清单。

**治理、报酬与审计补充核对（依据B05第1章）。** 个股买入前的管理层核对追加三项：①**治理情形与董事结构**（无控股股东／控股兼高管／控股不管理三类之一，及该情形下董事的实际作用）；②**报酬对称性**（奖金是否与职责范围挂钩、增量资本是否计息、“只奖不罚”的期权设计按其无下跌风险处理）；③**审计与披露信号**（审计师视谁为客户、有无跨期转移收入/成本迹象、有无选择性披露与盈利预测指引习惯）。任何一项无法获得证据时记为“待查”，不得以“管理层声誉好”替代。

**明确不做**：把伯克希尔的浮存金/递延税结构当作普通公司或本人账户的加杠杆许可；采用作者的“永不卖出优质资产”作为本人的持有规则（退出仍按§14）；以“股价与内在价值一比一”作为对市场的预判。

**流动性时点检查（依据B02第13章）。** 任何持仓（含长期组合）在买入许可前须完成一次前瞻流动性核对：

**杠杆与融资活动门（依据B02第5章）。** 融资活动本身不创造价值，只有在价格偏离价值时才改变股东价值；借债、还债、回购与增发按公允价值执行时不改变普通股价值。因此：

1. ROE、EPS、每股收益增长、P/E、P/B 都可能被杠杆放大或压低，单独升高不构成经营改善或价值创造的证据。低 P/E 可能正是杠杆风险的定价，"看起来便宜"不是通过价格门的理由。
2. 核对顺序固定：净债务明细桥接（含全部租赁负债，优先股视为债务，剔除受限现金及经营必需现金，处理应付股利与债务资产）→ 期初基数口径 → 账面杠杆与市场杠杆同时记录 → 未杠杆（经营）估值与杠杆后估值是否给出一致价值。
3. 股价高估会低估市场杠杆；不得用市场杠杆偏低来判断"低风险"，也不得只看账面杠杆。

**盈利口径门（依据B02第6章）。** 盈利能力必须用与资本成本同口径、且与账面价值配套的口径判断：

- 不用 ROA、EBIT、EBITDA、有形资产回报、ROC（净固定资产＋营运资本）或未经核对的 ROIC 作为盈利能力结论。它们分别错在分母含债务资产、分子漏税与税务筹划、把折旧摊销当无成本、把收购代价剔除、分子分母双错或用法定税率替代有效税率。
- 高 RNOA 单独不构成买入理由：**必须与普通股账面价值锚定同时使用**。会计盈利性不等于经济盈利性；研发、品牌、人力资本与渠道投入被费用化，会同时压低分母并污染分子。
- 经营负债杠杆（`OLLEV = OL/NOA`）可抬高 RNOA，但其分子效应是供应商在价格中加收的隐含利息，须同时核对；不能把高 RNOA 直接当作竞争优势。
- 收购后 RNOA 下降、存货减值等会计操作造成的盈利变化，不单独作为价值变化的证据；负 NOA（浮存型企业）时 RNOA 与 OLLEV 不可计算，不得用替代口径补一个正回报率。

**成长与可持续基准门（依据B02第7章）。** 只有能覆盖资本成本的剩余收益增长才算成长，盈利或销售增长本身不构成买入理由：

1. 挑战市场价格时使用**未杠杆**的剩余经营收益口径，并把价格隐含的增长翻译为具体的经营条件（利润率、周转率、销售规模），逐条判断可行性，而不是接受一个目标价或目标倍数。
2. 建立**可持续基准**：一次性项目（减值、重组、诉讼、罚款、税务调整、终止经营）与"重复但不可持续"项目（权益/衍生品公允价值变动、处置损益、汇兑损益）均不得进入基准。理由包括不可预测、以及与资产负债表公允价值计价重复计算。
3. 驱动分解须能指出**哪一项在变化**（利润率的分项、周转率的分项或经营负债），并给出行业分位基准作为参照；极端历史增长不得直接外推（均值回归是基准而非保证）。
4. 经营杠杆与固定资产结构属风险来源：销售下滑时固定成本与不可缩减的NOA会同时放大损失，须在压力情景中单列。

**风险与要求回报门（依据B02第8章）。** 门槛率（要求回报）是个人参数，不是模型输出：

1. **不用** CAPM、多因子模型或由其推出的 WACC 数值决定门槛率。理由：无风险利率含购买力风险、市场风险溢价不可知、历史beta标准误≥0.2、收益分布非正态。WACC 用价格替代价值会把错价算进要求回报——**计算价值挑战价格时不要把价格放进计算**。
2. 门槛率作为**记录在案的个人参数**：与"市场估计资本成本"分开列示（§7.1口径），改变它须记录依据并重算会计锚与剩余收益，不得用提高门槛率当作安全保证或重复惩罚。
3. 风险以**驱动情景 + 概率**呈现（销售、利润率、周转率、经营杠杆、融资），给出价值风险画像（各情景价值及其占价格比例）与下行概率；概率由业务理解赋值，不写成伪精确数字，也不以波动率替代基本面风险。
4. **分散化不是万能防护**：相关性在下跌市场趋近1；安全股票（低基本面风险）历史上提供部分下行保护但上涨期回报较低，且在2008年危机中失效。不得因"已分散"或"持有宽基"而省略个股与组合层面的下行分析。
5. 对冲不想要的风险时须核对工具、成本与**对手方风险**；杠杆化的对冲结构（如追加保证金机制）与§2禁止条款并列考虑，不因"对冲"名义而放松。

**账面安全门（依据B02第9章）。** 账面价值在估值中1:1进入、不折现，因此**账面本身不应含风险**；被高估的账面会抬高从价格反推的增长门槛。许可前必须完成下列检查并把结论写入研究卡：

1. **表外负债与或有负债**：列出飞机/设备采购承诺、容量或收入保证、赔偿责任、诉讼、税务争议、VIE/SPE 追索结构等，并明确采用四选项之一——全额入表／按概率打折入表／提高门槛率／放弃。选择要有理由，不得默认忽略。
2. **或有权益的悬置负债**：员工期权（内在价值＋时间价值−已确认费用，税后）、认股权证、看跌期权/回购承诺、可转债与可转优先股（转换损失＋期权价值），须估算并入表。**不得用摊薄EPS当转换损失的度量。**
3. **公允价值资产**：记录适用性、公允价值层级与 Level 3 占比；Level 1 处于投机期时须折价；警惕在利率上升前把债券重分类为"持有至到期"以规避减值。对自身债务采用公允价值选择权的公司，应把负债重估回应付金额。
4. **减值及时性**：商誉、无限期无形资产与长期资产是否在拖延减值；并购高峰之后的减值风险单列；折旧年限偏长者须核。
5. **养老金与递延税**：记录折现率与同业比较、匹配缺口、计划资产公允价值风险；递延税资产的估值备抵是否与亏损状态相称。
6. **租赁与供应链金融**：可变租赁支付、租赁折现率的选择、销售型租赁残值；反向保理应付的金额与条款是否披露。
〔历史政策关联叙述未公开；节号对应关系见同库历史政策节号映射。〕

**盈利质量门（依据B02第10章）。** 预测价值用的是**可持续且可外推**的盈利，所以当期盈利必须通过质量检查：

**收入确认专项（依据B01第3章，先于下列各条执行）。** 收入是盈利质量的入口。按"**卖方义务 → 买方验收 → 买方付款**"三个环节核对四个技术位，并把三项对照写入研究卡：

1. **四个技术位**（任一出现即按待查处理，需有解释与证据，不得因"审计无保留"放过）：①**未完成合同重大义务即确认收入**——签约不等于赚取，关注季末集中签约、买卖双方资金双向流动的"回旋镖"交易、把自身投资对象当客户；②**确认收入远超已完成工作量**——完工百分比法（POC）的进度估计与合同总成本估计变更、多年度许可把**全部许可收入现值一次性确认**；③**买方最终验收前确认收入**——卖方发起的 bill-and-hold（开票不发货）、发运给非买方（经销商、关联拖车、寄售代销人）、故意错发或早于约定期发货、退货权未失效即确认；④**买方付款不确定或不必要时确认收入**——客户依赖第三方拨款或存在使销售失效的"附函"、把原判"坏账"客户重新判定为可收回、卖方提供融资或超长付款期。
2. **三项对照**：①**收入确认脚注的年际逐字比对**（政策措辞变化，如"交付时"改为"交付或发运时"、客户返利从"冲减销售"改为"计入经营与销售费用"、经销口径由 sell-through 改为 sell-in）；②**DSO 与应收的季末跳升**——应收增速显著快于收入、DSO 同比跳升，且公司同时披露"延长付款条件／early buy program"时，按"增长率即将下滑"处理；③**公告时点**——新销售公告恰好出现在期末之后，或与公司公开吹嘘的长"连胜"记录并存时，加严检查。
〔历史政策关联叙述未公开；节号对应关系见同库历史政策节号映射。〕

**收入真实性专项（依据B01第4章）。** 上一项管"**什么时候**确认"，本项管"**有没有、算不算、算多少**"。四项检查任一命中即按待查处理，须有证据与解释：

1. **缺乏经济实质**：无风险转移的所谓"保险"（追溯保单、有限保险/finite insurance）；不具约束力的销售配**秘密附函**免除付款义务（"parking"）；货物发运到**卖方自有仓库或关联拖车**；**非货币／以物易物（barter）交易**（金额取决于公司自估，极易虚增甚至凭空捏造）；**"往返式（round-trip）"现金流**（卖给经销商后又从同一方回购）。
2. **缺乏公平交易过程（arm's-length）**：客户为**关联方、母公司、合资伙伴或公司自设实体**；单一大客户占比畸高且账期被不断展期；把**资产出售收益计入收入**而非一次性利得；把商标等资产转让给自己参与设立却声称"不控制"的合资并确认为销售。
3. **把非创收收款记为收入**：借款（含以存货抵押的短期融资）记为销售；**供应商返利／退款记为收入**（正确做法是冲减存货或采购成本）。
4. **正当交易但金额夸大**：按**名义总额**确认收入（只赚佣金却把整笔交易金额记为收入，毛利不变）；同一业务在不同渠道（线上／线下）采用**总额法与净额法混列**，人为抬高收入增长率。
〔历史政策关联叙述未公开；节号对应关系见同库历史政策节号映射。〕

**一次性项目与分类专项（依据B01第5章）。** 经营利润的质量还取决于"**什么被放进或移出经营段**"。三类检查：

1. **一次性事件**：资产出售收益是否被**冲减费用**或混入经营段（典型手法：把出售业务的收益作为 SG&A 费用的抵减，使费用"下降"而实际上升）；业务出售是否与**未来采购捆绑定价**（卖方少收一次性对价、多收未来产品收入；买方则相反，须**同时阅读交易双方的披露**）；是否通过**改会计政策**加速确认（如礼品卡失效收入）。
2. **分类迁移**：是否**几乎每期**都记录"重组费用"（把正常经营费用包装成一次性——出现频率本身就使"一次性"不成立）；是否把亏损部门的全部损益移入**终止经营**，并注意**被指定后成本分摊是否被抬高**使其余业务显得更赚钱；是否把**非经营/非经常收入**（利息、投资收益、向关联方收取的费用）计入收入或经营利润；**多数股权并表**会把子公司 100% 的收入与费用放在线上、少数股东权益放在线下，**线上经营利润因此高于经济归属**（示例：持股 60% 的子公司收入 100、费用 40，线上经营利润 60，线下扣 24，真实经济利润 36）。
3. **资产负债表分类的自由裁量**：以"是否具有重大影响"为名在**权益法**与**公允价值**之间摆动（盈利强时主张有影响、走弱时否认影响）；用**不并表的合资/合伙载体**表外化债务与亏损，并在同一载体上"只计收益、不计亏损"。
4. 执行要求：**"频繁出现的一次性项目"一律按经常性处理**，先还原到经营利润，再用还原后的数字计算一切回报率与增长率；还原范围必须包含公司**没有主动标出**的部分（被塞进费用抵减、被塞进"重组"、被移入终止经营的部分）。
〔历史政策关联叙述未公开；节号对应关系见同库历史政策节号映射。〕

**费用后移专项（依据B01第6章）。** 上面三项管**收入**侧；本项管**费用**侧——"**该记的费用有没有记、记在哪一期**"。成本的会计处理是"两步舞"：支出发生时先记为资产（第 1 步），利益实现时转入利润表记为费用（第 2 步）。四种手法都在这支舞上做手脚，任一命中即按待查处理，须有证据与解释：

1. **过度资本化正常经营费用**（只跳第 1 步）：把本应即时费用化的经常性支出记成资产——线路/带宽与租金类经营性支出（WorldCom 2000 年至 2002 年初把线路成本资本化）、客户获取与广告推销成本（AOL 1994 年起把 solicitation costs 记为"递延会员获取成本"）、软件开发的后期成本、以及把"补偿上年货款"改称"下年预付"（Diamond Foods 2012 年重述）。**两项固定对照**：①**自由现金流与经营利润的背离**——CFO 上升而 FCF 下降、资本开支意外大增且与公司原指引和行业景气矛盾（WorldCom：资本开支 +32%、经营现金流 −30%、FCF 由 +22.9 亿转为 −38.2 亿）；②**新设或不常见的资产科目**，尤其余额快速增长并涉及关联方时（Syntax-Brillian 的"tooling／inventory deposits"超过其报表存货总额，交易对手 Kolin 持股逾 10%）。**资本化政策的启用或变更本身即为红旗**：不论是否合规，其带来的盈利改善**一律不得计入可持续基准**。
2. **摊销或折旧过慢**（第 2 步跳得太慢）：摊销期或折旧年限明显偏长，**尤其是中途改长**（AOL 1995 年 7 月把 DMAC 摊销期由 12 个月改为 24 个月，单此一项虚增利润 4,810 万；Intel 2015 年把制造设备折旧年限由 4 年改为 5 年，2016 年折旧费用减少约 15 亿美元、约一半计入毛利）。行业性慢摊销（航空"**程序法**"存货：Lockheed TriStar 把实际成本高于预估平均数的部分先资本化，项目亏损后仍按每年 5,000 万"分期核销"；Boeing 787 至 2015 年 12 月累积 285 亿美元程序法存货）须单独建模，不能按普通存货周转理解。
3. **减值不及时**（卡在两步之间）：已失效或价值下降的长期资产仍按原折旧计划处理（认为预计可用 10 年的设备在第 5 年永久损坏，剩余账面应立即转费用）；**陈旧与超额存货**不计提跌价准备（Vitesse 2003 年计提为零，在销售仅增 3% 的情况下使毛利翻倍）。**突然宣布巨额重组费用，往往就是前期"该减不减"的迟来清场**。
4. **应收与投资不减记**（第二类资产从不进入两步舞，却可以"闭眼不看"）：坏账费用与**坏账准备占毛应收的比例**下降（Scholastic 2002 年应收 +5% 而准备 −11%、比例由 24.1% 降到 20.4%，不改则经营利润低 1,130 万）；**贷款损失准备相对不良（非应计）贷款下降**（New Century 2006 年 9 月把准备由 2.10 亿降到 1.91 亿、占不良贷款由 29.5% 降到 23.4%，不改则 EPS 由 1.12 降到 0.47）；向客户放贷以支撑销售（Signet 2015 财年某分部 61% 销售来自内部融资，两年后同店销售首次转负）；受损投资不减记并用关联或交易把亏损"**飞走**"（Olympus 以 tobashi 手法配合并购与剥离隐藏近 20 亿美元亏损）。
5. **三项年际对照（本项的可执行动作）**：①**准备金比率表**——坏账准备/毛应收、贷款损失准备/不良贷款、存货跌价准备/存货，逐年算出比率并与各自分母的增速比较，"**计提比例下降而分母上升**"是最清楚的一类信号；②**资本化与年限台账**——资本化金额占销售/R&D/经营利润的比例、折旧与摊销年限表逐期列示，任何变更单独留痕并**还原后重算**可比期间的费用率与利润增速；③**现金流交叉**——CFO、资本开支与自由现金流三者方向是否自洽（费用资本化会**同时**美化利润与经营现金流）。
〔历史政策关联叙述未公开；节号对应关系见同库历史政策节号映射。〕

**隐藏费用专项（依据B01第7章）。** 前三项查"费用是否被留在资产端"，本项查"**费用根本没有进表、或金额被记小**"。三类检查（任一命中即按待查处理）：

1. **当期交易不记或少记**：期末收到的发票被拖到下期（Symbol 未计提 350 万美元 FICA，季度净利虚增 7.5%）；**供应商返利/抵免**——以未来涨价换取签约时的"返利"并当日冲减费用（Sunrise Medical 用**附函**锁定、对投资者与审计师均未披露），尤其警惕**来自供应商的现金流入**（现金正常应流向供应商）与**关联方供应商**（Syntax-Brillian 的 Kolin 抵免 2.147 亿美元＝其累计毛利的 1.5 倍，且从未收到现金）；应计提的**或有损失**未计提；**表外采购承诺**未在附注中核对（作者提醒："有时未入表的承诺与或有负债比表内负债更重要"）。
2. **激进会计假设**：租赁**残值**假设被调高（Deere 由 55% 升至 63%，可折旧由 45% 降到 37%）；**自保**精算假设变更（Rent-A-Center 2006 年 6 月改假设后，其后四季的盈利增长几乎全部来自这一次变更）；**养老金四项假设与计量日**（Navistar 剩余寿命 12→18 年省 2,600 万；Raytheon 计量日由 10/31 改为 12/31 得 4,100 万＝每股 0.09＝全年约 10%；Lucent 2004 年养老金收益 11 亿美元＝经营利润的 91%，2002–2004 年累计 28 亿对累计经营亏损 60 亿）。
3. **释放以前计提的准备**：负债与收入同为贷方余额，把贷方转入费用即减少费用。典型案例：WorldCom 冲回通用准备抵减线路成本；Under Armour 2016 年第四季度冲回全年奖金计提 4,800 万美元（出现**负 SG&A**、每股 +0.07 且未显著披露）；Sunbeam 的"饼干罐"；Marvell 借购买会计**无需先记费用**就取得"饼干罐"并据以逐季裁量；Dell 2007 年 8-K 审计调查结论（**季度结束后记账结账的最初几天**、有时经高管要求或知情下调整准备与应计负债，**跨科目转移超额准备、以超额余额冲抵不相关费用**，保修准备超额却不释放）。
4. **固定动作**：把 `other current liabilities/accrued expenses` 等"软负债"**相对收入的比率**逐年跟踪并找出单项准备；**假设变更与准备释放一律单独留痕**，给出"变更前假设下的可比费用"与"释放金额对当期利润的贡献"，并**用还原后的数字计算一切比率与增长**。
〔历史政策关联叙述未公开；节号对应关系见同库历史政策节号映射。〕

**收益后移与平滑专项（依据B01第8章）。** 上市公司**压低当期利润**的动机是**平滑与可预测**。本项与"收入确认专项"互为镜像：一个把未来挪到现在，一个把现在挪到未来，**两者是同一量级的操纵**。四类检查：

1. **递延收入与准备**：逐季核对 `递延收入期初/新增/使用/期末` 与环比（微软 1998 年初 20 亿→1999 年 3 月 42 亿、6 月骤停，随后季度收入环比 −6.6%）；**政策变更要与"雨天到了"分开论证**（微软采用 SOP 98–9 后按比例确认区间由 20%–35% 降到约 15%–25%，1999 财年收入 +1.7 亿）；异常膨胀的**未披露准备**（Enron 2001 年初超 10 亿美元）须视为重大红旗。
2. **衍生品与无效对冲三问**：①收益**远大于**被对冲标的的损失（WAMU 2004 年 16 亿收益对 5 亿损失＝3 倍）；②"对冲"与标的**同向**变动（即投机）；③**报告前数日才改动会计处理**（GE 2002 年末过度对冲面临 2 亿美元税前费用，2003 年 1 月初季度结束后发明新做法，数年后被 SEC 认定为舞弊）。
3. **收购前"节流"与存续期**：核对收购双方**财年差异**造成的 stub period 收入（3Com/U.S. Robotics：两月仅 1,520 万 vs 前季 69,020 万）；核对**交割前一个季度目标公司收入**是否骤降（Platinum 环比 −1.44 亿、同比 −2,300 万——**是"扣收入"还是"业务萎缩"，两种情况都要警觉**）。
4. **季末停单**：业绩已达标、奖金已满时把当期销售移到下期——这同时暴露**管理层按修饰报表而非商业逻辑做经营决策**。
〔历史政策关联叙述未公开；节号对应关系见同库历史政策节号映射。〕

**未来费用提前专项（依据B01第9章）。** "反向日"：把未来费用提前到当期，让当期难看、明天好看。两类手法：

1. **提前核销资产**：把尚可受益的资产一次冲掉（AOL 把 3.85 亿美元递延营销成本一次冲销并称"会计估计变更"，此前该项对应未来 8 个季度每季约 4,000 万摊销、而 1996 财年经营利润仅 6,520 万）；**存货减值过度并回转**（NVIDIA 2016 年存货减值升至 1.12 亿，2017 年卖出已核销商品 5,100 万并回转，毛利率 +70 个基点）；把减值/清理包装成"一次性"并列在线上之下（Toys 'R' Us 3.966 亿中 1.84 亿为"战略性存货重定位"）；缩短折旧或摊销年限；**新任 CEO 的"大洗澡"**（Sunbeam/Dunlap：任命当日股价 +60%，后因重述抹去 1997 年净利近三分之二并破产）。
2. **提前计提准备**：把未来的（甚至不存在的）费用在当期计入并形成准备（Sunbeam 1996 年 12 月 3.376 亿重组＋1,200 万，SEC 认定重组费**至少高估 3,500 万**、另不当设立 1,200 万诉讼准备；计划裁 100 人却按 200 人计提、每人 2.5 万美元包，剩余 250 万日后释放；Symbol 为收购 Telxon 计提 1.859 亿含虚构成本并高估存货核销；Xerox 以 1 亿"未知风险"准备＋约 20 项超额准备共 3.96 亿在 1997–2000 年释放；H.J. Heinz 以预付费用与提前入账抬高次年利润）。
3. **三条触发条件**：①**减值或重组后的次年异常好转**——须核是否来自**回转**（给出回转比例、对毛利率与经营利润的贡献、以及已核销存货是否真的卖出）；②**新任高管上任期的大额减记**——一律按待查处理；③**重组频率检验**——每年都发生的"重组"是经常性成本，不得剔除（与"一次性项目与分类专项"同一条规则）。

**现金流分类与不可持续现金流专项（依据B01第10–12章）。** "盈利易被操纵、现金流是硬指标"是误解——**现金流同样能被操纵，且很多做法完全合规**。现金流量表三段的划分规则留有大量裁量空间（作者称之为"**段内地理游戏**"），因此本专项分三步执行：

1. **地理核对（流入是否被搬进经营段）**：核对是否把**借款**包装成经营流入。判据是**追索权与经济实质**——无追索地出售应收 → 经营流入；**保留信用风险（含回购承诺等变相追索）→ 视为借款、融资流入**（Zoomlion 声称无追索保理 52.0 亿元，但附注披露须在银行收回设备时按公允价值回购，实质仍是追索）。典型手法：以存货/应收为抵押的"出售"（Delphi 假卖存货 2 亿美元，剔除后全年 CFFO 仅 0.68 亿、第四季度 −1.58 亿；Peregrine 伪造应收出售）；**表外载体的双向交易只记流入不记流出**（Enron）；**"回旋镖"交易**（Global Crossing 向客户卖出容量的同时向同一批客户购买容量，收入记经营流入、支出记投资流出）；**自定指标替代 CFFO**（Delphi 报表 2.68 亿 vs 公告 16 亿）。
2. **地理核对（流出是否被搬出经营段）**：任何"**听起来像正常经营成本**"的投资段项目都要提问——费用资本化（WorldCom 两年虚增 CFFO 85.88 亿：线路成本 47.6 亿＋其他 38.28 亿）；**多年期软件许可改按资本租赁**（Salesforce 把付款移到融资段"资本租赁本金偿付"，该行位于现金流量表倒数第二行）；**存货采购列投资**（Netflix 的 DVD 采购；与 Blockbuster 口径不同导致 CFFO 不可比）；**外购专利与在研技术列投资**（Cephalon 两年约 11.3 亿，若归经营则 CFFO 分别为 −3.497 亿与 −4.140 亿）；**非现金取得（票据支付）日后列为偿还债务**（Biovail，金额藏在"补充现金流信息"附注）；**非现金供款完全不进现金流量表**（Diageo 5.35 亿英镑威士忌、IBM 2.95 亿美元国债供养老金）。
3. **不可持续现金流（把未来的现金流提前支取）**：四条"生命线"——①**拖延付款**（Home Depot 把 DPO 由 22/23 天拉到 34 天、次年 41 天，第一年 CFFO 由 28 亿升至近 60 亿、2002 年回落至 48 亿；vendor financing 使"买存货"永远不进经营段，T-Mobile 2015 年 5.64 亿美元被埋在融资段）；②**加速收款**（Tesla 2016 年 Model 3 可退定金 3.5 亿＝当年改善额的 88%；Silicon Graphics 用提前付款折扣把 DSO 由 49 天降到 37 天并在季末操纵现金余额；UTStarcom 2008Q1 的"转机"来自应收 −6,500 万、应付 +6,600 万与放弃早付折扣）；③**少买存货**（Home Depot 存货流出由 −10.75 亿降到 −1.66 亿、次年回到 −15.92 亿）；④**一次性收益**（Sun 2004 年 20 亿美元和解款，其中 16 亿立即确认收益，CFFO 由 10 亿升至 22 亿，现金流量表**未单列**）。判据：**同比复现需要再来一次更大的动作**；`DPO/DSO/DSI` 的异常摆动、以及"**积极推进营运资本管理**"的表述，都按**待查**处理。
4. **固定动作**：①**CFFO 与自由现金流同时看**（费用资本化会美化 CFFO，但 `FCF = CFFO − 资本开支` 会把问题还原：WorldCom 由 +22.89 亿转为 −38.18 亿）；②**必读 MD&A 的 `Liquidity and Capital Resources`**——现金流驱动因素的说明常埋在那里（Home Depot 自己写明 DPO 与单店存货变化）；③**逐季比对披露变化**（"神秘新安排"成为 CFFO 驱动因子即为大事；Peregrine 仅在风险因素中加一句 12 个词）；④**任何一次性盈利提振都要问"它如何影响现金流量表"**。

**关键指标专项（依据B01第13–14章）。** 前面各项查"数字怎么来的"，本项查"**管理层选择用什么数字给你看**"。分**业绩指标**（收入的代理、利润的代理、现金流的代理）与**健康指标**（应收、存货、金融资产、债务与流动性）两类，各按下列要求留痕：

1. **指标定义台账**：逐期记录公司使用的**非 GAAP 指标**（同店销售、ARPU、订户数、订单/积压、EBITDA 及其变体、调整后利润、自由现金流、可分配现金流等）的**定义原文、口径与分母**，并**逐季比对定义是否变化**——定义变更通常恰好发生在指标恶化之时（Coach 2013 年把"面积扩张≥15% 的门店"重新纳入同店基数；Tellabs 2006 年 12 月把 DSO 由期末余额改为季度平均，使披露的环比增幅由 16 天变为 5 天；Thomson Reuters 通过**追溯重分类**"ongoing businesses"把 2012 年基数下调近 5 亿美元以报出 2013 年正增长）。
2. **非 GAAP 必须逐项对账**：每个调整项都要能回答"**它是不是经常性**"（Global Crossing 把"维护费、客户违约、留任奖金、常规监管费"列为一次性；Groupon 的 adjusted CSOI 剔除线上营销、股权激励与收购费用，把 27 个月 GAAP 累计经营亏损 5.39 亿美元变成盈利 1.4566 亿；Whirlpool"ongoing earnings"27 年中 23 年剔除重组费用，2016 年 10 月被 SEC 问询）。**频繁出现的调整项一律按经常性处理**，与"一次性项目与分类专项"同一规则。
3. **代理指标不得替代现金流**：`EBITDA`、`cash earnings`、`cash EBITDA` 都**不是现金流指标**（不含营运资本变化，也不含坏账/减值/保修计提）；资本密集型企业尤其误导（Gogo 把网络设备与系统软件的生产安装成本经折旧剔除）。**任何自创现金流指标都要与 `CFFO` 和 `FCF` 并列**（Delphi 2000 年自定"Operating Cash Flow" 16.36 亿 vs 报表 CFFO 2.68 亿／FCF −10.04 亿；2003 年 12.20 亿 vs 7.37 亿／−2.68 亿；IBM 把"融资应收"变化从自由现金流中剔除，2012 年该项近 30 亿美元＝其自定自由现金流的 16%）。
4. **健康指标四类失真与加回规则**：①**应收**——出售应收会**同时**抬高 CFFO 并压低 DSO，比较时须**加回季末仍未收回的已售应收**；警惕**改名为应收票据**（Symbol：DSO 119→90 天）或**挪入现金/票据科目**（UTStarcom 把银行票据 1.0 亿美元计入现金）；**DSO 用期末余额**计算以防渠道压货（期末余额更代表季末交易）。②**存货**——把存货挪入长期资产（Merck 长期部分占 13%→25%）须加回；警惕"存货削减计划"式虚假动作（Symbol：虚假分录、卸货区不入账、卖出承诺回购）与**自创新存货指标**（Tween"店内每平方英尺"与上年"总存货"口径比较）。③**金融资产**——减值与准备的**列示口径变更**视为重大事件（New Century 把贷款损失准备与自有房地产准备合并列示，合计 2.365→2.394 亿看似增加，实际贷款损失准备 2.099→1.916 亿，不改则 EPS 由 1.12 降到 0.47）。④**债务与流动性**——表外债务与不良资产的隐藏是"账面不可信"的极端情形（Parmalat 未披露债务 79 亿欧元、净资产由 +21 亿变 −112 亿，高估 133 亿欧元）。
5. **与审计师公开争执＝最红的红旗**：审计师**无法表示意见/保留**、或公司**公开发布多份新闻稿反驳审计师**，都要单独列出并追查原因（Parmalat 2003 年 10 月审计师无法就 Epicurum 交易出意见，相关衍生合约收益**超过其 2003 年上半年全部税前利润 1.199 亿欧元**且此前未披露；公司随即连发四份新闻稿公开反驳）。

**并购会计专项（依据B01第15–17章）。** 并购会计会**系统性**让收购方显得更好看：其中一部分（经营成本沉入商誉/无形资产、经营流出移入投资段、**继承来的营运资本在交割后释放为经营流入**）**不是管理层蓄意**，而是准则与合并口径的必然结果；另一部分才是手法。三组检查：

1. **交割前后（收入与利润）**：①**stub period 双向操作**——目标公司可能在交割前**藏收入、堆费用**（Salix：2014Q4 收入仅 1,300 万美元＝同比 −95%，2015Q1 为 0，交割后三季共确认 13 亿美元）；②**交割前大额核销**（把费用留在当期、利润留给未来）；③**非独立交易**（Krispy Kreme 在回购加盟商前向其售出 70 万美元设备，同时把收购价提高同等金额，并**把这 70 万记为收入**以维持连胜纪录）；④**交割后制造新收入流**（FPA Medical 把 5,500 万美元"返利"记为销售收入——经济实质是净收购成本 1.42 亿美元、收入为零；Intel 以低价出售业务换 Marvell 高价采购晶圆，把一次性收益转为经常性收入；Valeant 交割后把 Medicis 的收入确认由 sell-through 改为 sell-in，SEC 发函）；⑤**或有对价（earn-out）下调**会**直接产生利润**，且逻辑上说明**被收购业务未达目标**（示例：或有对价由 4,000 万降至 3,000 万＝1,000 万收益；Li & Fung 2012 年上半年 1.98 亿美元＝经营利润的 51%）。**交割时隐藏亏损**的极端案例是 Olympus 把约 20 亿美元亏损经**商誉与不并表关联方**"飞走"（6.74 亿美元"中间人费用"远超投行常规的 1%–2%）。
2. **现金搬运**：①并购型企业**不得只看 CFFO**——固定改用 **`并购后自由现金流 ＝ CFFO − 资本开支 − 现金并购支出`**（Tyco 1999–2002 年买入 700 多家公司，四年报告 CFFO 年年为正 35.5/52.8/69.3/57.0 亿美元，而并购后自由现金流**四年全为负** −32.2/−13.3/−89.7/−8.7 亿美元）；②**"收购合同/客户"的支出**属经营性（Tyco/ADT 每客户约 800 美元；其舞弊版本把合同单价由 800 提到 1,000 并收取 200 美元预付"连接费"，SEC 认定 1998–2002 年虚增 CFFO **7.19 亿美元**）；③**出售业务时保留应收、或不承接应付**（Tenet 出售 27 家医院时保留 **3.94 亿美元**应收并在交割后收回；Treehouse 2016 年 27 亿美元收购**排除 9 家工厂的应付账款**）；④**用受限现金账户支付目标公司的营运资本与研发**（Whirlpool 收购合肥三洋后），使支出既不进经营段也不进自由现金流；⑤把**付给在职合伙人的 earn-out** 全部列为融资流出（MDC Partners）。**判据**：现金流量表出现**新行项目**即为重大事件（Softbank 2005 年把 850 亿日元拆为 450 亿业务出售＋**400 亿"预收"记经营流入＝全年 CFFO 的 69%**，2006 年报表因此新增"increase in deferred revenue"一行）。
3. **指标与增长口径**：①**必须拆出三套增长率**（原有业务／被收购业务／合并后），pro forma 披露与"目标公司贡献"都要读；②**同店销售的 comp base 是否随并购变化**（Starbucks 2004 年起收购区域特许经营商并把既有门店**立即并入基数**，2007 年 9 月美国客流史上首次下降、12 月同店转负后**宣布不再披露同店销售**）；③**"有机增长"的定义**是否剔除了目标公司**收购前签下的合同**（ACS 的"internal growth"只剔除上年 normalized revenue，使目标公司新签的每季 1,000 万美元合同被算作自身增长）；④**非 GAAP 与 GAAP 并列**——长期"A+ 对 D−"即否定该指标（Valeant 2013–2016 三年 GAAP 净利 **−27 亿**、非 GAAP"cash earnings"**+96 亿**，差额超 **120 亿**；其唯一 GAAP 亮眼的 2014Q4 含出售 Allergan 持股的 **2.87 亿**美元税前一次性收益）。
4. **固定收口**：并购型公司的核心结论**必须建立在还原后的有机增长与可持续盈利之上**；**披露不足时提高门槛率或放弃**，**不得把"并购带来增长"本身当作买入理由**。

**法证复核专项（依据B01第18–19章）。** 本章组把全书收口为**流程要求**（不新增阈值）。两层：

1. **会计问题出现时的处置顺序（Hertz 的教训）**：①**不采信"预计无重大影响"**——初步重述几乎总是远小于最终结果（Hertz 先称 2,800 万美元、最终 3.49 亿；Toshiba 先称 12 亿、最终近 19 亿美元）；②**在能分析真实业绩之前先离场**，不为"看起来便宜"而买入正在更正会计错误的公司；③**审计师对内控拟出具否定意见、CFO 在年末审计准备期仅提前一周离职**等事件，按**独立红旗**处理；④**内部会计调查（尤其针对收入确认）一经公告，即按重大事件处理**，并跟踪调查委员会的**构成变化**（Toshiba 改为全部无利益关系的外部专家后，问题反而更大）。
2. **十条法证准则的动作化清单（第 19 章）**：①**怀疑是竞争优势**——资本市场天生传递好消息，保持客观者受益（Enron 处在成熟监管行业却"几乎不产生会计利润与现金流"，而收入 5 年增 10 倍）；②**关注变化，并追问"为什么是现在"**——比"为什么"更有价值，因为它逼你计算"**没有这个变化，数字会是什么**"（Ulvac 改完工百分比法）；③**穿过会计问题看业务问题**（Hertz 重述后业务远不如先前理解的赚钱）；④**关注文化与不良行为的温床**（Qwest 前 CEO："最重要的事是达成数字……达不成时我们停下其他一切"）；⑤**不盲从公司自设的盈利框架**——先问"**这个指标回答的是什么问题**"，再问"这个问题是否值得回答"（Linn 的"可分配现金流"依赖管理层对成长性/维护性资本开支的主观划分）；⑥**薪酬指标决定战略**（Valeant 的激励指标为"cash EPS"，剔除并购相关全部成本，于是"用现金大举收购、任何价格"都推高指标）；⑦**在披露里"位置决定一切"**——通读全年文件，**对过于技术、枯燥的章节最警觉**（Under Armour 的 4,800 万美元冲回只出现在 10-K 一张无关季节性表格的脚注里）；⑧**每一杆都算**——公司要求把重组、召回、诉讼、并购整合等"当作没发生"时，视同**要求"重发一球"**，只在极罕见情形可接受（Whirlpool 连续二十余年在非 GAAP 中剔除年度重组费用）；⑨**行为模式具有持续性**——在某家激进会计的 CFO 很可能在新东家照做；一次渠道压货后，去查其历史上同类动作是否都伴随收入不及预期；⑩**谦逊与好奇**，并**如实记录与更正自己的判断错误**。
〔历史政策关联叙述未公开；节号对应关系见同库历史政策节号映射。〕

1. **GAAP 的五个已知缺口**按固定方式处理：员工期权与可转债的转换损失→已计入悬置负债（不再重复扣）；养老金→把**计划资产预期回报**从经营利润中剥离（它混淆了经营与养老金投资），并把预期回报率与折现率与同业比较；经营租赁→按借款利率×期初租赁负债把隐含利息从经营利润移入利息费用；**无重大影响权益投资**的公允价值损益→剥离，或改用**穿透盈利**（但不得与公允价值账面并用，否则重复计算）。
2. **红旗诊断必须计算并留痕**：`ΔSales/ΔNOA`、`%OI增长 vs %销售增长`、`ΔPM vs ΔATO`（PM升+ATO降、PM降+ATO升均为红旗）、`净利/CFO`、`ΔSales/Δ毛应收`、`ΔSales/Δ递延收入`、`存货/销售`、`净应收/毛应收`、`ΔSales/Δ保修负债`；并核对折旧年限、重组计提与回转、递延税估值备抵的回转。
3. **追踪足迹**：`经营利润 = 自由现金流 + ΔNOA`。当期利润与现金流的背离必须能解释；不能解释时按待查处理。
4. **非GAAP数字必须与GAAP对账**，且不得长期剔除经常性费用（折旧、股权激励、租赁费用）；非盈利指标（点击量、NPS等）不替代收入与利润证据。
5. **操纵更可能发生的情形**（融资/重谈借款、可能违约契约、管理层或审计师更换、报酬与盈利挂钩、治理薄弱、关联交易、特殊事件临近、被收购、结构性表外载体）出现时，加严检查而非降价买入。

**估值与信息口径纪律（依据B05第6章）。** 研究估值时按下列五条执行，与§6.1 许可门、模板G2/G5 配套：

1. **先答三问再谈价格**：任何标的须先写清①未来现金流入是否存在、②其时间与数量、③所采用的无风险利率（本项目记录所用利率并注明日期）；**未与现金流入流出的数量和时间挂钩的股息率、市盈率、市净率与成长率，不得用于估值**。
2. **拒绝伪精确**：内在价值是**估计值与范围**，不是点值；范围过大以致无法得出结论时记为"**无结论**"，不得强行取点值，也不得只取最有利假设。利率或未来现金流预期变化后须重算。
3. **区分投资与投机**：以"下一个买家愿出更高价"为理由的买入一律否决；对无法判断未来现金流入的新兴与快速变化行业，按投机处理，不进入许可门。
4. **盈利口径纪律**：分析经营成果用**股东盈余**（财报盈利＋合理非现金费用−维持长期竞争地位与产量所需的资本开支，含必要营运资本）与**透视盈余**（归属自身的被投资公司盈利，而非收到的分红）；**禁用 EBITDA 或以"(a)+(b)忽略(c)"式"现金流"数字**作为可分配现金或估值依据；**折旧是真实经济成本，不得与购买法摊销混同**；账面价值**只在同一年度比较其变动比例**时作追踪指标，不充当内在价值指示器。
5. **不因叙事改变口径**：管理层的"市值管理"表述、股东结构描述、"1 美元留存创造 1 美元价值"式陈述、以及本书作者关于商誉、通胀与长期期权的推理，**均不改变估值口径与许可门**；引用"模糊的正确优于精确的错误"须注明其为作者对自身负债估计的立场，不构成本项目对估值精度的授权。

**会计信息质量与操纵防御（依据B05第7章）。** 研究材料须按下述五条留痕，与§6.1 许可门、模板H 节配套：

1. **先答三问，再谈"报表不错"**：任何标的的财报阅读须能回答①**公司大约值多少钱**、②**实现未来规划的可能性有多大**、③**管理层的工作表现有多好**；只罗列 GAAP 数字视为**未完成**，缺项写"未知"并说明缺什么。GAAP 是"告知义务的开端，而不是结尾"。
2. **对"盈利连续超预期"默认怀疑**：凡出现连续多个季度"恰好达到或略超预期"，须写清是**真实经营改善**还是**会计调整所致**，并把该现象登记为红旗；记录当期的**会计政策与估计变更**（含折旧年限、减值时点、商誉摊销与减值方法、递延税税率口径、退休福利假设、准备金、资本化政策）。
3. **剔除项必须追查去向**：任何"一次性／重组／减值／并购整合"剔除项，须回答"**被剔除的成本去了哪里、以后会不会回来**"，并登记该项目近五年出现次数与金额；"大洗澡"式季度与随后的"持续超预期"组合一律按"待查"处理。
4. **薪酬与期权成本不接受"无现金即无成本"**：提供有价值的东西即发生成本；含股票期权的标的须做**成本调整**或采用等价的**股数稀释路径**并记录方法；管理层以"期权难以估值／价外无价值／不来自公司金库"为由不确认成本的，按**红旗**记录。
5. **长期假设与回报主张须可反推**：退休金、自保等长期假设回报率须与**资产配置**反推一致（不一致记待查），并注明美国与非美国假设是否系统性不同；任何"两位数回报"主张须给出**起点、期数与年化**；默认机会成本为"**平均回报减成本**"，即"什么都不知道"的被动投资者通常会胜出积极投资者。**净利润与运营利润分列**，记录报告期内已实现/未实现盈亏及出售时点，不因"净利润下降X%"类标题改变判断；**税务口径**（递延税税率与分层、税负归属判断）与**退休后福利负债**（假设与上限）一并留痕。

**信息获取与换手纪律（依据B06第4章）。** 五条：

1. **一手信息的合法边界（不可逾越）**：调研与交流**只能**使用公开披露信息与合法交流得到的行业常识。**严禁**获取或使用内幕信息、未公开重大信息或他人违规传递的信息；交流对象若主动提供非公开重大信息，须**立即终止该话题且不得据以决策**。作者自身的限定须照录：“我们所寻找的信息既不是仅有少数人才知道的秘密，也不是不可泄漏的机密。”
2. **四条可操作方法**：①**定期接触行业内部人**（作者口径：每月至少与每个主要行业代表交谈一次；“10次闲谈中可能有两次发现重要信息”，即高频低命中率的持续过程）；②**必问“你最敬佩的竞争对手是谁？”**，并把回答记为竞争者质量的独立证据；③**记录发起方**——**主动邀请优于被动接待**（被动接待往往意味着该公司正在向全市场讲同一个故事），被动接待所得信息不得单独作为新信息依据；④**供应方与销售方都有一手信息**（与§6.3业余优势来源清单合并使用）。
3. **调研日志与印证要求**：每次交流须留日期、对象、职务、发起方、关键回答、可验证事实与待核事项；底稿须能在本人不在场时被复核；**交流得到的事实必须在下一份财报或公开披露中得到印证后方可进入模型**。
4. **换手纪律（最高优先级）**：**“发现新的好公司”本身不构成卖出理由**——卖出须由§9的预设触发条款或§11的**量化优势差**支持，且该差额须覆盖**摩擦成本与税负**；换手须写书面理由并列明新标的相对现有持仓的优势差；**换手率本身作为年度复盘指标**，无书面理由的高换手视为流程违规（书内教训：麦哲伦首年换手率343%、随后3年300%；作者自述“许多股票过去我只持有了几个月的时间，其实应该持有更长一些的时间”）。
5. **能力圈扩张标准与“不设风格”的边界**：跨行业研究的合格标准是**能列出该行业盈利的3–5个关键驱动因素及其观察指标**，而非“成为行业专家”；达不到即记入“未知”并降低仓位上限。**“不必被迫在某一风格内选股”是被允许的**（作者：“当所有成长型股票被过分高估时，成长型基金经理就不得不继续购买股价已经明显过高的成长股……只能瘸子里面挑将军”），但这**不等于可以不写理由地换股**；§6.3的**风格漂移检查针对载体**，本条**针对本人账户**，两者共同要求“**每一次选择都要有证据**”。

**边界**：本段**不新增任何买入授权**；“与上市公司交流”**不构成本项目向第三方索取非公开重大信息的授权**；“用一手信息提前一步”仅限公开信息与合法交流；作者“进攻再进攻、不断替换”的表述与其对高换手率的自我批评在同一章内并存，**本项目以第4条的换手纪律为准**。本章业绩数据、价格倍数、持仓比例与图表读数均为书内自述或目视估读，**未外部核验**。

**组合结构、责任归属与第8条法则边界（依据B06第5章）。** 五条：

1. **第8条法则须四项配套才可执行**：书内规则“如果长期国债的投资收益率高出标准普尔500股票指数的红利收益率6个百分点或更多，那就应该卖出股票而买入长期国债”**不是自动交易指令**。执行前必须写明：①两个收益率的**口径、数据源与观察时点**（本人组合对标非标普500时，须替换为本人基准并同口径计算）；②该偏离属**战术偏离**，须在§5与§9留痕并**事先设定偏离幅度上限**；③**不改变§3的长期目标配置**；④**事先写明恢复条件**（利差回落水平或连续月数），**不得临场决定**。
2. **双重研究（责任归属）**：同一标的须有**两条相互独立的研究路径**（本人一手调研与财报底稿／公开披露与第三方研究的独立证据）；两条结论不一致时，必须在模板D写明分歧与倾向理由；**“只有一个理由”的持仓视为未完成研究**。**不以“冷门”标榜，也不以“知名”避险**，两者同样须过§9/§11。
3. **注意力配置与报价隔离**：**报价查阅与决策分离**——查阅报价只用于执行与记录，**不在查看报价的同一时段内形成买卖决定**；分批建仓按模板K执行；研究与交流时间须显著高于交易与报价查看时间，每月复核一次实际分配。作者把不断更新价格的行情机关掉，理由是“屏幕上不断变化的股价，太容易让人分心了”。
4. **评估周期按年**：本人账户的绩效评估**按年**（模板M），**不按日、不按周**；日常只做**流程合规检查**（底稿是否齐备、许可门是否通过），不做短期业绩评价。作者的原则：“只要每年年终根据投资业绩进行一次评估就够了。”
5. **恐慌中的对称问法，且现金不提供灾难保护**：反面情景与正面情景**必须对称书写**；“**为极端灾难而超配现金**”**不构成§4之外的许可**——§4的现金与防御资产用途是**流动性缓冲与再平衡弹药**，不是“灾难保险”（作者原述：一旦摧毁一切的大灾难发生，“即使存在银行的现金也会和股票证券一样，变成废纸一张”）。

**边界**：本段不新增任何买入、加仓或债券工具授权；**第8条法则的6个百分点阈值不构成自动交易指令**；“股价大跌是最佳投资机会”类表述不构成加仓或择时授权；不因本书观点改变§3配置与§4防御资产许可清单。

**规模、持仓数量与退出纪律（依据B06第6章）。** 五条：

1. **持仓数量的研究预算化与"研究仓位"管理**：新增标的的数量上限由**本人可支配的研究时间**决定，不由市场机会决定；每新增一个标的须写明**跟踪计划**（信息源、频率、下一次复核日）。允许设"**研究仓位**"（对标作者"以后看看再说"），但必须①标注为研究仓位；②写明**删除条件**（连续两次复核无进展，或已确认不属于§3任一类型）；③**不计作"已建仓"**，以避免重复加仓。**不以持仓数量或持仓风格评价自身能力**，但组合中每一只标的必须能逐条说明投资理由与§3类型归属。
2. **禁止对"濒临灭亡"型标的摊低成本，且以债券价格作为困境警示**：**绝对不增持面临破产风险的亏损公司股票**；不得以"机构也在买""价格已经很低""跌幅已大"作为继续持有或加仓的理由（作者案例中，15美元、10美元、4美元处均有"精明老练的投资人"持续劝买）。**凡持仓出现债券价格大幅折价（书内案例为面值100美元→不到20美元）或信用市场明显不信任的信号，须立即转入§9排雷复核，复核结论前不得加仓**；理由为破产清偿顺序上债券先于股票，故"债券不值钱时股票更不值钱"。**无论买入价多低，跌到零即亏损100%。**
3. **周期型与困境反转型标的必须事先写明退出触发**：买入时即列明可观测指标及其阈值（每股收益、产品价格、产能利用率、毛利等）与复核频率，**不得以"长期持有"回避退出决策**；出现"**预期差**"信号（**本人最乐观预期劣于市场最悲观预期**）时按§14与§6.2执行退出或降级。作者原述："投资周期型股票，重要的是要抓住正确时机及时抛出，获利了结，不然的话，好股票就会变成烂股票"；"投资周期性股票就像玩21点扑克牌游戏：如果赌的时间太久，最终会把赢来的钱再输光"。
4. **流动性不入许可门**：**"卖出是否方便"不构成买入理由**，也不得替代§9排雷与§11安全边际；流动性只进入两处——①建仓的**进度与自身价格影响**（模板K：分批计划、可接受的价格影响幅度、"因自身买入导致价格偏离"时的暂停条件）；②极端情景下的**可退出性**（计作风险项）。**不得因标的规模小、流动性差而降低研究要求，也不得因看好在同一价位区间无限加量。**
5. **既有持仓优先重检，且类型不得固化**：在寻找新标的之前，**先对已有持仓按同一底稿与同一标准做完整重检**（第11条林奇投资法则"最值得买入的好股票，也许就是你已经持有的那一只股票"给出的是**重检优先，不是加仓授权**）；任何新增买入前须回答"本次买入相对于对已有持仓追加的判断依据是什么"，若为"新标的更有吸引力"须给出**同口径对照表**（预期回报、确定性、估值、风险）。§3的公司类型是**研究入口而非标签**：至少每年重新判定类型归属，变更须写理由；**"看好"须有与观点一致的仓位表达**（观点与仓位不一致时须写明是有意背离还是操作疏漏）。

**边界**：本段**不新增任何买入、加仓或工具授权**；**第9/10/11/12/13条林奇投资法则均不构成本项目的自动交易指令**（第11条须先满足第5条的重检优先与对照表要求；第12条只作情绪校准；第13条须与§9排雷并行；第10条只作隐喻）；作者关于**海外配置比例（10%~20%）、"满仓"与"任何时候都必须持有一定比例的现金"的表述，均不改变§3配置与§4防御资产许可清单**；本章业绩、规模、持仓与价格数据均为书内自述或目视估读，**未外部核验**。

**消费观察、长期图形与季节性现象的边界（依据B06第7–8章）。** 三条：

1. **消费观察必须落到可核对的公开数据。** 购物中心与门店客流、渠道陈列、家庭成员或熟人的使用反馈等观察**只作线索**，不入档为证据；任何消费类标的的买入须由下列可核对数据支撑：①**单店营业收入（同店销售）及其口径**；②**存货水平与铺货/滞销的区分**；③**扩张的资金来源**（自有现金流／加盟商资金／债务／股权，"尤其是依靠借债进行高速扩张更加危险"）；④**门店数与市场渗透率/饱和度及其分母假设**。**印象类观察（"生意很好""排长队"）不得单独构成买入理由。** 第14条林奇投资法则（"如果你喜欢一家上市公司的商店，可能你也会喜欢上这家公司的股票"）在本项目**只作研究触发**，不构成买入授权。
2. **长期"收益线—股价线"图形校验只作红旗触发。** 当长期图上股价线明显高于收益线时，须按§9复核并重新计算§11的反向预期，写明"是否仍满足价格门"；**不得据图形单独作出买入或卖出决定**。反之（股价线平行或低于收益线）只表示"不构成该红旗"，**同样不构成买入授权**。
3. **季节性、税损抛售与"一月效应"只作现象登记。** 作者转引的历史统计（年末税损抛售→年初反弹；小盘股1月平均涨幅6.86%对同期平均1.6%）**未核原始序列、未给起止年份**，**不得作为择时、加仓或调整仓位的依据**；价格下跌本身不是买入理由（与本节"股价比过去低了，并不是买入的理由"一致）。**不得据单一信号（如股息惯例中断，作者案例为EQK绿地"为省下区区10万美元"取消连续6年的增息惯例）直接下结论**，须转入§6.1现金流与流动性复核。

**行业恐慌与资产负债表透视的边界（依据B06第9章）。** 三条：

1. **行业恐慌只作研究触发，须有可核对数据与"景气改善"证据。** 任何"某行业已被过度悲观定价"的判断，须同时留痕：①**媒体/共识叙事及其口径缺陷**（本书案例：标题把"商业地产崩盘"写成"房地产市场崩溃"）；②**可核对的行业数据**（本书所用为中等住宅价格、NAHB购屋能力指数、抵押贷款呆账比例；不得以个别案例或情绪替代）；③**利率与融资条件等背景变量**。**除非有强有力的事实和数据表明行业景气度确实正在改善，否则按"赌一个被行业不景气折腾得奄奄一息的公司回生"处理——否决，而不是按便宜程度打折**（作者自举反例：1984年石油天然气"不可能再恶化"却继续恶化）。
〔历史政策关联叙述未公开；节号对应关系见同库历史政策节号映射。〕
3. **内部人买入与"回购价高于市价"只作线索，不构成买入授权。** 作者的第15条林奇投资法则自带反例——"并不是说公司内部人士就不会错误地估计自家公司股票的实际价值（像新英格兰银行和得克萨斯州银行，尽管股价一路下跌却愚蠢地更多回购股票）"。因此：①公司回购价高于当前市价、内部人（含CEO）买入或未减持，均登记为**证据线索**，须与§9排雷、§11反向推算并行；②**不得据单一信号下单**；③**借债回购不改变本项目杠杆与融资政策**（税收抵免与省股息是评估资本配置效率的机制，不是加杠杆的许可）。

〔历史政策关联叙述未公开；节号对应关系见同库历史政策节号映射。〕

**特许经营（加盟）模式的许可提示（依据B06第10章）。** 三条：

1. **"轻资本扩张"不改变许可门。** 加盟模式下"设立新店的资金全由加盟商自己负担"，扩张不受母公司资本约束，因此**增速快不代表质量高**；研究须核对：①**加盟商的单店经济性**（每小时产出量与单价、开店投资、回本周期，本案例为"平均投资10万美元"与"最初两年预计实现50%的税前投资利润率"，**口径未写明**）；②**特许方收入结构**（本案例为销售收入5%的特许权使用费＋产品收入4%提成）；③**关店率与续签率**（先行指标，须在原始披露中核对）。**不得以"加盟商很多""开店速度快"作为买入理由。**
2. **"负债占总资产X%"只作提问，不作结论。** 作者的处理方式可作为模板：发现"负债占总资产的31%"后**标记并追问原因**，再用**自由现金流对利息与到期的覆盖**判断偿债路径（本案例：自由现金流5,400万美元/年、1991年利息费用2,100万美元→`2.57倍`覆盖，管理层称1993年清偿完毕）。**管理层关于现金流与偿债时间表的答复属口述证据，须以原披露复核**；杠杆结论仍按§6.1的杠杆与融资活动门、流动性时点检查执行。
3. **体验式调研只作线索。** 亲自购买/使用（"我在那儿剪过头发，我亲自调研过了"）属**n=1的手样本**，须按模板K留痕并落到公开披露；**不得以"我喜欢这家店"或"我不喜欢这家店"作为买入或否决的理由**（作者本人即给出"喜欢招股说明书胜过喜欢门店"的例外）。

〔历史政策关联叙述未公开；节号对应关系见同库历史政策节号映射。〕

**低迷行业与"沙漠之花"标的的许可提示（依据B06第11章）。** 三条：

1. **行业低迷只作研究触发，须有份额与退出证据。** 任何"低迷行业中的优秀公司"论点，须同时给出①**行业需求趋势**（停滞或收缩的证据）；②**竞争者退出名单**（本书样本：25家最大地毯公司中13家退出；活动房屋贷款领域山谷联邦、密歇根保险公司下属机构、花旗相继退出）；③**本公司市场份额的年度变化**。**"行业差"本身既不是买入理由，也不是回避理由**（同章内航空业西南航空+10倍对照东方/泛美破产、钢铁业纽可+75倍对照伯利恒−46%）。作者提出的第16条法则「在商场上竞争绝对不如完全垄断」为**经验陈述**，不构成规则。

1. **我的风险容忍度是否随着价格上涨而上升**？（若是，按警报处理——"投资风险的最大来源是相信根本没有风险"。）
2. **报价里的风险补偿处于什么位置**？记录信用价差/风险溢价相对长期正常水平的位置（观察量见研究手册§13.3）；**只记录位置，不预测拐点**。
3. **同一组事件我是否只有一种解读**？（写出乐观版与悲观版两版；出现"全部利好"或"全部利空"即为情绪化解读的证据。）
4. **是否因"这次不一样"放宽了贷款标准、估值假设或安全边际**？（与§6.1 的质量门、对手方与费用核对并用。）
5. **杠杆与追加保证金路径是否算清**？（触发价、强制卖出、赎回叠加后的自我强化，见§4 与§6.1。）
6. **是否把"极端恐慌"当作抄底授权**？**机会须同时具备资金、期限与承受力三项**，缺项按不可执行处理。

**明确不做**：以情绪指标或"钟摆位置"择时；以"熊市源于前一轮牛市涨得过头"作为买卖时点依据（该主张是**解释**，不是择时授权）；把风险–收益关系写成"高风险＝高收益"（正确表述是"看起来风险更高的投资必须显得能提供更高收益"）。

**信贷窗口与再融资检查（依据B04第9–11章）。** 任何涉债或高杠杆标的，除既有偿债与流动性检查外，必须记录**融资环境**这一外部变量：

- **窗口状态**：当前能否再融资、条款松紧、利差与风险溢价相对长期正常水平的位置；**窗口关闭只改变研究假设与生存压力情景，不构成买入授权**。
- **条款保护**：限制总债务、限制现金分红、最低净资产等条款是否已被放弃；是否出现 PIK／toggle 等"推迟违约"工具（其后果是**违约晚来而杠杆更高、跌得更惨**）。
- **再融资路径**：到期结构、可替代融资来源、"重大不利变化"条款被触发的后果；**若假设"到期可以再融资"，须写出该假设失效时的处置计划**。
- **逐底竞争识别**：当出现"过多的钱追逐过少的交易""尽职调查减少""愿意买低质量证券"三项中的两项以上，按**慷慨资本市场**记录（红色警告），并复核是否因竞争压力放宽了标准。
- **明确不做**：以"牌在借款人手里／在资本提供者手里"作为择时依据；以"很容易得到钱"降低安全边际要求；把"房价长期总会上涨"等长期叙事当作抵押品价值或地产暴露的免检理由。

**双重风险与攻守定位自检（依据B04第12–13章）。** 每次新建仓、加仓与再平衡前回答并留痕：

1. **此刻我更怕哪一种风险**——"买错资产导致亏钱"，还是"错过好资产没赚到钱"？写下当前倾向及理由（依据：估值水平＋身边投资人的行为）。
2. **我有什么资格调整攻守比例**？调整定位的前提是**①自证具备所需洞察力②愿意承担判断错误的风险**（两者缺一，按维持原政策处理）。
3. **位置证据是否齐全**？须同时给出**估值证据**（PE／债券收益率／资本化率／收购倍数相对历史正常水平）与**行为证据**（发行与申购、尽调强度、条款松紧、媒体与资金流）；**证据不足时不得调整**。
4. **投降自查**：我是否因为**别人赚钱或亏钱**而在改变原计划？若是，按"投降"处理并回到原计划（写下当时价格与我方估值区间）。
5. **泡沫判据**：我是否在用"涨幅大"当泡沫证据？**泡沫的标志是"价格再高也不会赔"＋借钱买入**，不是涨幅；出现"无风险高收益"话术时按最高级别警报，并用"为什么人家卖给你而不是自己买"两问反驳。
6. **两种资本是否具备**：**情绪资本**（能否忍住不割肉）＋**财务资本**（能否追加保证金或补仓）。缺一即按"不可执行"处理；**不得以"跌下去终会反弹"作为持有或加仓理由**（2008–2009 的股票指数两年合计仍为负）。

**明确不做**：把"周期位置判断"当择时；把表13–1 类检查表量化成分数或自动信号；把"底部"当作可确认的时点；临场执行"越跌越买"（须事先经 §9 修订并写清金额、条件与现金底线）。

**极值共振与频度纪律（依据B04第18章）。** 极端环境的判定采用**多维共振**，而不是单项信号。逐项记录是否同时出现、并附来源日期：

- **顶部共振**：心理乐观最大化——；信贷额度最大化——；价格最高——；预期收益最低——；风险最高——；最后一波追涨买入——。
- **底部共振**：心理落到最低——；信贷融资最低（几乎融不到资）——；价格最低——；潜在收益最高——；风险最低——；最后一个乐观者投降——。
- **规则**：单项不构成极值判定；共振只改研究假设与攻守倾向评估，**不构成择时授权**；“顶部/底部是一段时期而非一天”。本清单**不得量化为分数或自动信号**。

**配置顺位与追踪误差（依据B03第4章）。** 战略配置的起点是**风险承受力**，不是目标回报：

1. **先定承受力、再定股债比例**。不得用"我需要多少回报"倒推配置；**组合风险若超过承受力，执行中会被放弃**。早期宁偏保守，之后再上调。
