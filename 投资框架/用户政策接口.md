# 用户政策接口

本包不附维护者的个人IPS。P01–P10仅定义规则语义，没有默认比例、金额、期限或阈值；通用研究与方法解释无需先填个人资料。

## 唯一政策来源

通用研究和方法解释不要求先提供IPS；涉及个人适配时，指向一个用户IPS文件，记录其版本和SHA-256。用户在自己的工作区从[空白模板](../使用边界.md#个人资料)建立政策。研究运行清单只保存政策引用与确认状态，不复制参数值，避免第二套参数漂移。必要与可选输入、缺失时允许完成的范围见[输入输出约定](../使用边界.md)。

资产、备用金、期限、收入负债、支出货币、税务身份、账户与权限均须由使用者提供或核实。未知保留未知。基础货币由使用者指定，不固定为维护者原框架中的人民币。

## P01–P10 语义映射

保留编号以便复用现有手册和执行字段；这里只定义语义，不提供默认数值。

| 编号 | 使用者需要定义的政策 |
|---|---|
| P01 | 主动权益预算、分母、纳入的工具及重复敞口处理 |
| P02 | 单一股票上限、例外范围与批准程序 |
| P03 | 公司类型及对应上限、混合类型和类型变更处理 |
| P04 | 首次建仓、研究层级及完成更完整研究的条件 |
| P05 | 科技或相关集中敞口、穿透方法、观察线及响应 |
| P06 | 再平衡目标、偏离单位、检查频率和实施规则 |
| P07 | 回撤口径、分级响应、暂停或复核及例外程序 |
| P08 | 冷静期、起算时点、交易日历与例外 |
| P09 | 主动资格评估、同口径基准、评估期限和后果 |
| P10 | 终值敏感性提示、计算口径与进一步研究义务 |

原 IPS 的配置、额度和期限没有自动适用性。空白用户政策不得被维护者参数、书籍案例或模型猜测补齐。编号含义改变需迁移接口，不可继续使用旧编号表示另一种规则。

## 研究与执行的边界

五门 G1–G5、证据分层、关键未知、同源去重、正反向估值及反方要求沿用既有方法。政策不完整时可以做方法研究并标出缺口；不能生成“已获准新增仓位”的结论。用户附带材料和扩展内的“本人”“本 IPS”及带数值的执行条款，应先判断属于个人政策、书籍案例还是研究公式，不能整体替换成通用政策。

研究结论、用户对 IPS 的确认和真实交易授权分别记录。当前项目不连接账户或执行交易。

## 冲突与版本

- 同一次运行固定方法版本和用户政策版本；开始后不静默切换最新分支。
- 用户扩展可以增加行业问题、证据或书籍；与基础方法或 IPS 冲突时列出差异，不能静默覆盖基础文件。
- 政策变更保存新版本、理由、确认记录及生效范围；旧报告保留事前版本。真实 commit 未知时使用 null，并保留资源 SHA-256。
- 修改基础方法或接口时保存旧版本并重新核对研究义务，不以简化入口为由省略必要研究。
