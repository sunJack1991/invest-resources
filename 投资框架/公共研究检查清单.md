# 研究检查清单

本页由既有研究方法提炼，用于脱离个人主库后的可移植核心研究。没有附带旧章笔记、原书图表或个案事实；不把压缩后的检查清单当作已完成原材料核验。方法来源章节见sources.md（原引用未随公共库提供），相关底稿写入使用者工作区。

## 商业、管理与资本配置

将商业论点拆为谁付款、购买原因、替代方案、量价或留存、成本、投入、现金及竞争响应。至少两条独立外部证据支持关键商业论点；同源转载和作者跨书复述只算一次。熟悉产品只是线索。

费雪15要点按以下问题逐项记录证据、反证、未知及失效条件，不用平均得分掩盖诚信或生存问题（B07第一部分第3章及附录）：

1. 市场空间能否支持增长；排除只报巨大TAM。
2. 管理层能否持续开发新产品与市场；查兑现史。
3. 研发能否商业化；费用率和专利数量不能单独证明有效。
4. 销售组织与渠道效率；查复购、留存、压货和补贴。
5. 当前利润率的实际质量和分部来源。
6. 维持利润率的办法、必要投入及竞争反应。
7. 员工关系、流动及实际处理问题的记录。
8. 高管协作、激励和权责，防止强人依赖。
9. 接班与管理梯队深度。
10. 成本分析、会计和内控；外部资料不足时不声称审计完成。
11. 行业特有优势能否复制、替代或绕开。
12. 长期盈余观是否体现在客户、供应商和投入行为中。
13. 增发、融资和完全稀释股数如何影响每股价值。
14. 管理层在坏消息时是否如实沟通。
15. 诚信、关联交易及对小股东的行为；其他优点不能抵消重大诚信问题。

保守投资四要素另核生产营销研发与财务能力、人的因素、持续企业优势、支付的价格。长期成长不取消价格和组合约束。回购核支付价格与净注销；并购核现金、股份、承担债务、整合投入与增量回报；分红及留存均比较机会成本（B05第1–2、4–7章；B07第二部分）。

## 财报、重构和现金

完整研究读取五年四表与适用附注；较短历史或轻量研究说明范围和限制。统一会计范围、期间、单位、币种、税与重述；区分母公司、合并、归母与NCI。

- 张氏战略八看：战略、资产管理与竞争力、效益质量、成本机制、项目质量、风险、价值和前景。沿战略→资金去向→资产有效性→利润来源→现金及回报建立因果链（B12第1–4、6–9章）。
- 三支柱为核心利润、其他收益和杂项收益，两搅局为资产减值与信用减值。先映射具体报表科目、利息、税及归属；核心利润不等于NOPAT，跨准则不机械搬公式，也不重复扣已含费用。
- 该书口径的核心利润获现率为`CFO/(核心利润+其他收益)`；分子分母税息、非现金项目及营运资本不完全匹配，亏损或近零分母停用机械比较。经验值不作为个人硬阈值（B12第3章）。
- 客户提前收款与供应商商业信用一起看：应收及票据、合同资产、预付款、存货、应付和合同负债。现金改善可能是结构优势、季节波动、保理、延迟付款或释放库存，不能直接等同回款能力改善。
- 建立利润→非现金→经营债权/存货/经营负债→税息及其他→CFO→投资与融资→现金变动桥，受限及归属现金分开。应收减少也核出售、核销、汇率与合并范围。
- 逐项映射经营与融资：`NOA=经营资产−经营负债`，`NFO=金融负债−金融资产`；NOA−NFO到普通股权益存在其他权利时完整桥接。
- `ReOI_t=OI_t−r_oper×NOA_(t−1)`。同税后、同范围与相容期初基数下，`ROE=RNOA+FLEV×(RNOA−NBC)`。明确OI/NFE、净利和税分配，负或近零分母不机械解释比率。
- 权益及股数桥包括净利、OCI、分红、回购、SBC、发行转换、NCI和稀释。期初期末股数、基本/稀释及分配路径一致；SBC是经济代价，不能只因非现金而忽略。
- 母子范围、现金权利及控制依据分开。母子差额用于生成问题，不倒推为真实内部交易规模。商誉减值后的高ROE不自动证明经营改善。

## 会计与治理调查

B01第四版四组方法用于生成调查，不直接指控舞弊：

| 组别 | 全部检查方向 |
|---|---|
| 盈利七类 | 收入过早；虚构收入；一次性或不可持续收益；当期费用移向以后；隐藏费用或损失；当期收益推迟；未来费用提前 |
| 现金流三类 | 融资流入列经营；经营流出移到其他类别；用不可持续活动抬高经营现金 |
| 关键指标两类 | 营运指标造成错觉；资产负债表或相关指标掩饰恶化 |
| 并购三类 | 并购抬高收入利润；并购抬高报告现金流；并购修饰增长与关键指标 |

逐项执行“异常→经济解释假说→附注与独立来源→未解问题→门状态”。核年际收入确认、DSO与账龄、退货验收/附函、关联客户、总额净额、资本化、准备金、负债时点、非GAAP调节和持续成本；会计列报合规仍可能影响经济解释。

并购对照原有、被收购、合并后三套增长；交易及整合是否实际上经常发生。购买营运资本后的收现可抬高CFO，须连同收购支出、维护/成长投入分析。审计意见、治理、激励、监管与内控同时核对；关键真实性未知，G2不能通过。

## 正向、反向估值及复算

- 对象、现金流、折现率、币种、名义/实际、税、时间轴和股数一致。FCFF配经营要求回报，FCFE/股权RI配权益要求回报；永续增长须有经营与再投资依据且`r>g`。
- 股权RI：`RI_t=E_t−r_e×B_(t−1)`，`V=B0+未来RI现值`；清洁盈余与资本交易完整桥接。经营RI从NOA和未来ReOI出发，再扣匹配净融资及其他优先权利。
- 企业到普通股价值桥包括净融资、NCI、优先权利、受限/非经营资产与股数；现金不重复加回。商誉、费用化投入及回购改变指标时先还原经济含义。
- 反向估值求一个具体隐含增长、利润率、持续期或投入回报，列固定变量、域、路径、终值、解的存在与唯一性、残差；无解时解释。改变r也要重算RI资本费用和相关预测。
- 独立校验说明输入和模型差异；共享盈利预测的PE、PB、DCF和RI不是独立证据。负分母停止机械倍数比较。
- 情景包括量价、利润率、税、维护/成长投入、融资与股数，输出价值、分配、每股回报及悲观永久损失；与同币种/税费/分配的可投资宽基比较机会成本。
- `1−P/V`表示相对价值锚的价格折价，不是损失概率。终值敏感性按用户P10处理，无默认阈值；书籍经验比例不变成个人参数。
- 教学例是虚构假设：B0=100、E1=12、r=10%、RI永续不增长，则RI1=2、V=120。NOA=80、OI1=10、r_oper=10%时ReOI=2，经营价值100；NFO=20则权益80。这些数值只用于检验公式，不能给真实标的默认使用。

## ETF、防御资产与特殊分支

ETF核指数覆盖/加权/调仓/总回报、注册地与具体份额、复制/借贷/托管/对手方、成分重叠、底层流动性、清盘与替代、全成本及退出。追踪差异为同口径基金总回报减指数总回报，追踪误差是差异收益的波动，已在净值扣除的费用不再重复扣。上市、交易和经济货币分开。

封闭式基金折溢价用带符号`P/NAV−1`，分配率不等于回报；折价收敛需依据。固收核信用、久期、到期/赎回、汇率、用途时点及可变现性；债券基金不等于个人锁定到期兑付。顾问费用冲突、托管/交易权限和退出另核。

| 场景 | 额外必查 | 不作的简化 |
|---|---|---|
| 银行 | 存贷款、信用迁徙、拨备、资本、流动性和重定价 | 直接套工业FCFF |
| 财产险 | 事故年度、准备金发展、再保险、浮存金成本、承保与投资分开 | 浮存金当免费自有现金 |
| 寿险 | 保证利率、久期匹配、退保、资本及信用 | 用财产险指标替代 |
| 零售连锁 | 成熟与新店、同店量价、回收、关店及租赁 | 扩张等同同店增长 |
| 订阅软件 | 付费口径、留存、服务成本、获客回收、SBC | ARR、GMV或用户数等同利润 |
| 周期重资产 | 成本曲线、利用率、库存、时滞与低谷融资 | 顶峰利润外推、低PE自动便宜 |
| 资产或反转 | 优先权利、税费折价、可变现性、重整和稀释 | 账面值等同小股东兑现值 |

生存表按重要付款时点核“可用现金+经营/可实现资产流入+可确定融资−利息本金/维护/刚性支出”；做融资不续、账期缩短和更长消耗情景。授信注明承诺、条件与可撤销性，不将未用额度都当现金。无法建立适合模型时先列缺口，不硬套普通公司公式。

## 行为、反方、决策和复盘

周期沿需求→盈利/经营杠杆→信用融资→投入供给→价格建立情景，不由周期标签自动调仓。事前验尸覆盖竞争监管、治理会计、现金融资、买价及个人被迫用款；列信号、反证和动作。

记录经历死角、过度自信、攀比、回本冲动、叙事、后见之明；区分生存与波动、过程与结果、技能与运气。反方挑战关键因果链，不只补一段笼统风险。ESG落到盈利、账面、要求回报或回避决定。

拟议执行核用户政策P01–P10、证券身份、日历、单位、费用、到账、前后权重和每批触发/暂停/失效；本包只研究，不实际下单。每份财报对照原假设、实际、口径与价值及五门变化。组合与主动子组合分别计TWR/XIRR，匹配外部现金流和双基准；无数据只做定性，保留不行动与错误卖出样本。
