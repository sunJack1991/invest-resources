# 可移植研究方法

本页由个人主库短手册的研究流程生成；不包含维护者IPS数值。用户政策按[政策接口](用户政策接口.md)提供，专题定义见[检查清单](公共研究检查清单.md)。详细章笔记与历史案例记录见同库阅读记录目录；实际未读取的内容不能声称已读。

## 1. 路径、研究层级与证据

流程：个人资金与IPS → ETF/个股分流 → 分类、商业与财报 → 生存与正反向估值 → 反方 → 五门决策 → 执行与复盘。组合风险、财报治理、商业质量、价格回报分别通过；待查视为未通过，不能用总分抵消重大缺陷。

每个结论留存：结论、证据定位、推算/假设、反证、未知、对动作的影响。区分书籍原则、个人政策、公司事实、推算、情景；公司数据标A原始披露或报价、B推算、C情景，书内转述不得冒充已核公司事实。

来源优先为法定披露/审计附注、指数基金官方文件，再到可核第三方数据。至少两条独立外部证据支持商业论点；同源转载或作者跨书复述只计一次。管理层承诺与经营及现金兑现核对。

按IPS P04选择轻量/完整研究。轻量仍须五道许可门、关键财报/治理/生存核查、一个反向数值、简化悲观情景、独立估值校验与反方。完整增加五年四表及附注、经营融资重构、三情景、投入融资和股数桥接。不适用写理由，缺数据写未知，不补造数字。

## 2. ETF、防御资产与实施

先核指数覆盖、加权/调仓、股息口径、宽基属性，再核注册地、份额、复制、借贷、托管、对手方。主题/行业/因子基金预算归属按IPS。

穿透发行人、行业、地域、币种，与直接持仓去重。交易货币、底层经济货币和家庭支出货币分开；上市地不等于收入来源。目标日期基金核to/through滑行路径及双层费用；名称不赋予防御资产资格。

总成本含管理费、顾问及最低费、点差、佣金、换汇、税收时点和退出成本。`追踪差异=基金总回报−同口径指数总回报`，追踪误差是差异收益的波动；净值已扣基金费，不重复扣。核NAV/市价同日同币种、底层流动性、清盘与替代载体。

封闭式基金用带符号`P/NAV−1`，核杠杆、分配是否返本、赎回权与收敛依据；分配率不等于总回报，折价不保证安全。固收核信用、久期、到期/赎回、汇率及用途时点，债券基金不等于到期锁定兑付。

顾问登记、报酬、保管/交易权限、冲突和退出分别核。税务在个人身份、账户及当前适用规则核实后计算；递延税益不当永久免税或即期现金。不预填当前费率、税率、产品名单或交易授权。详见[研究检查清单](公共研究检查清单.md)。

## 3. 公司分类、商业与管理

两分钟说明谁付钱、为何购买、收入利润驱动、主要风险及价格隐含什么。林奇六分类：缓慢增长、稳定增长、快速增长、周期、困境反转、资产型。分类决定问题和估值，按IPS P03归类；混合公司拆分。

| 主题 | 必答问题与输出 |
|---|---|
| 需求与成长 | 市场空间、量价/留存、竞争、增长对补贴/并购的依赖；列投入和现金需要 |
| 费雪15要点与四要素 | 产品潜力、研发、销售、利润率、人员、管理深度、沟通和诚信；逐项证据/反证/未知 |
| 护城河 | 客户为何不换、对手为何难复制、持续多久；写观察指标与失效条件 |
| 治理与资本配置 | 留存、分红、回购、并购、报酬、关联交易；列支付代价、净股数和增量回报 |
| 周期与资产 | 正常化利润、产能/存货、资产可实现性；列压力价格、成本与融资路径 |

熟悉产品只提供线索；闲聊法限公开合法信息。控股资源不等于归母股东现金。回购看价格和净注销；并购计现金、股份、债务与整合投入。商誉减值后的高ROE不自动代表经营改善。详见[研究检查清单](公共研究检查清单.md)。

## 4. 财报、会计与生存

阅读顺序：业务/风险 → 审计 → 利润表 → 资产负债表 → 现金流量表 → 权益变动表 → 附注。统一期间、单位、币种、范围、政策及重述；区分母公司、合并、归母与NCI。

| 底稿 | 必做检查 |
|---|---|
| 利润 | 核心利润、投资/公允价值、非经常项、税、NCI到普通股盈利桥接；核心利润不等于NOPAT |
| 资产 | 现金受限/归属、应收账龄/保理、存货、在建、商誉、抵押与关联款；能否变现 |
| 现金与融资 | CFO到现金变动、维护/增长投入、到期债务、租赁/担保、融资关闭与现金耗尽时点 |
| 权益与股数 | 净利、OCI、分红、回购、SBC、发行/转换、NCI；对价与稀释不遗漏 |
| 合并控制 | 合同权利、范围变化、抵销、母子差额和现金归属；差额只生成问题，不直接推内部交易规模 |

保留张氏战略八看、三支柱两搅局、获现率、两头吃、杜邦与周转率的定义和分母。重构逐项映射：`NOA=经营资产−经营负债`，`NFO=金融负债−金融资产`；NOA−NFO到普通股权益的其他权利须桥接。

`ReOI_t=OI_t−r_oper×NOA_(t−1)`。同范围、同税后及相容期初基数下，`ROE=RNOA+FLEV×(RNOA−NBC)`；负或近零分母不作机械比率。高ROE、EPS增长、低PE先查杠杆、回购、减值和费用化投入。

排雷完整覆盖利润七类、现金流三类、关键指标两类、并购三类，并查高管/董事会/审计/监管环境。应收出售、负债时点、并购取得现金可能美化CFO；非GAAP加回对照持续经济代价。红旗启动调查，不直接定罪；关键真实性未知不新增。详见[研究检查清单](公共研究检查清单.md)。

## 5. 正向估值、反向预期与机会成本

统一对象、现金流、折现率、币种、名义/实际、税、股数和时间轴。FCFF配经营要求回报，FCFE或股权RI配权益要求回报；企业到普通股桥接净融资、NCI、优先权利、受限/非经营资产。

| 方法 | 关系与前提 |
|---|---|
| DCF | 三情景列量价、利润率、税、投入和资本需求；永续增长须有经营依据，折现率大于增长率 |
| 股权RI | `RI_t=E_t−r_e×B_(t−1)`；`V=B0+未来RI现值`，需清洁盈余与完整资本桥接 |
| 经营RI | `经营价值=NOA0+未来ReOI现值`，再扣匹配净融资及其他优先权利；不重复加现金 |
| 相对估值 | 核正常化/前瞻、基本/稀释、周期/杠杆；EV与股权口径分开，负分母停用 |
| 安全边际 | 写价值锚、误差来源与可接受价格；`1−P/V`只是折价，不是损失概率 |

从当前价格反推一个具体数值：隐含增长、利润率、持续期或投入回报。列固定变量、求解域、路径、终值、是否有解/唯一与残差。r改变须同时重算RI资本费用和未来路径；共享盈利或预测的PE/PB/DCF/RI不自动算独立证据。

虚构稳态例：B0=100、E1=12、r=10%、RI不增长，则RI1=2、V=120。经营例NOA=80、OI1=10、r_oper=10%、ReOI不增长，经营价值100，NFO=20则权益80。实际研究须验证稳态、会计与分配前提。

三情景输出价值、分配、每股回报、悲观永久损失和生存路径，与同币种/税费/分配的可投资宽基比较。P10增加终值敏感性，不自动否决。保留B02对长期确定性预测的批评；DCF是本框架综合选择的情景工具。

银行资本/拨备、保险承保/准备金、周期正常化、资产变现、反转与并购各用对应分支，不硬套普通工业企业FCFF。详见[研究检查清单](公共研究检查清单.md)。

## 6. 周期、行为与反方

用需求 → 盈利/经营杠杆 → 信贷/融资 → 投资供给 → 价格的因果链做情景。融资关闭和股债同跌进入生存测试，周期位置不独立生成调仓命令。逆向须有价格、证据和持有能力。

登记经历死角、过度自信、攀比、回本冲动、叙事与持有期限。复盘单列运气与风险的影响，并说明定性归因依据。区分波动/永久损失、收益需要/承受能力、过程/结果。尾部赢家、作者自述和事后极端样本不证明方法可复制。

事前验尸覆盖竞争/监管、会计/治理、现金融资、买价过高、使用者用款；各写损失路径、信号和动作。最强反方挑战关键因果链，列会改变看法的证据。ESG进入盈利、账面、要求回报或回避决定，不以单一评级代替基本面。详见[研究检查清单](公共研究检查清单.md)。

## 7. 决策、执行与复盘

模板D五门分别为通过/待查/否决，待查与否决不新增。观察、买入、加仓、持有、减仓、退出分别写理由；低于成本、涨跌幅或故事流行不单独产生动作。

执行前按IPS核P01–P10、资金用途、冷静期、证券类别、股数、限价、费用及交易后权重。分批列总额、条件、暂停与失效机制，未成交也留记录；风险纠错可独立于回撤阈值处理。

每份财报做原假设/实际/口径变化/原因/价值与门状态差异表。每个论点有观察指标、来源、证伪条件和复核触发。长期持有仍复核价格、资金与机会成本。

归档事前版本，过程与结果四格评价，拆市场、风格、汇率、盈利、股数与估值贡献；无数据只记定性，保留未买入及错误卖出样本。总组合与主动子组合分别计TWR/XIRR，双基准、总成本及主动资格按IPS。
