# invest-resources

投资阅读详细笔记、批次记录、复算底稿、疑点处置、阅读进度及完整方法资料的公共资源库。资源版本0.1.0，与[投资研究Skill](https://github.com/sunJack1991/invest-research)分开维护。

- 资源目录（原引用未随公共库提供）：按书号、类型、路径和SHA-256定位。
- [来源与阅读记录](阅读记录/书籍来源与阅读记录.md)、[逐章笔记](阅读记录/逐章笔记)、[批次记录](阅读记录/批次记录)。
- [详细研究方法](投资框架/专题/研究方法详解.md)、[阅读标准](阅读书籍标准.md)、[使用边界](使用边界.md)。

初始公共副本覆盖250份逐章笔记、112份批次记录，另有复算、定位元数据、结构和进度、未解项与原披露核验台账；共484份阅读文件。保留原有缺口和未完成状态，不把脚本检查或历史阅读记录当成当前Agent已经读过原书。

公共内容是保留研究证据的适配副本，已去除维护者政策参数和本机临时路径。历史IPS关联叙述不公开，其节号与文件对应另存[纯节号映射](阅读记录/历史政策节号映射.json)，不含个人政策正文或参数。因此公共副本并非原记录逐字全集；本地原件和适配审计完整保留。原书文件、解码全文、图像、个人IPS、资产和独立报告不在此库。公开适配不回写原件。

## 获取与引用

完整使用：克隆本库并固定commit；或安装Skill提供的完整资源包。按需使用：从Skill的resources.lock.json读取实际commit、资源目录和文件指纹，只下载相关条目，不能把main当永久版本。GitHub仓库下载不等于全文进入模型上下文。

引用格式：仓库URL、40位commit、相对文件路径、章节/行或段落、文件SHA-256、实际读取范围及日期。来源不可读取或无法核对时记录缺口，不冒充已读。

## 补充与升级

维护者可以直接在本库补充笔记、书目和核验资料。新书使用新的稳定书号，不重排旧编号；先记录材料来源、版本和实际阅读状态，不复制整本原文。保留旧结论及修订原因，区分书中观点、方法选择、事实、推算和用户政策。

内容变更后提升资源版本，显式运行：

```sh
python3 -B scripts/update_catalog.py --version 0.1.1
```

提交修改、目录和manifest后，Skill维护者审阅并更新资源锁定。资源库可以独立增加内容，旧安装和旧报告继续引用其原commit。个人IPS和报告保存在各自工作区，可添加自己的资料，不提交本库；提议改进可通过PR，经维护者合并才改变官方版本。尚未指定开源许可证。
