# B06 第18章 我的房利美公司纪事

来源：B06第一册《战胜华尔街》第18章，v2 **1791–1898行**（108行、10,128字符；1791行为页眉、1792行为章题）。**14次图像引用/2个图像文件**：`00016`×13（装饰图标）、`00017` **表18-1小结**（FNM／房利美公司／**68.75**，1992/1/13）；本批已目视。spine29**无脚注链**，含译者注1条（1884行）。`original_report_verified=false`。

## 1. 论证推进（按年份的时间线，本章的结构本身即方法）

**（0）引子（1793–1799行）**：作者自1986年起每年在《巴伦》周刊推荐房利美（1986年称"**美国境内真正最具价值的公司**"——"房利美的员工人数是富达投资公司的1/4，而利润却是富达公司的10倍"；1987年称"**终极储贷社**"；1989年答埃布尔森"还是那个你听我说过的联邦国民抵押贷款协会"）；**仓位事实**：麦哲伦最后3年房利美为"**头仓——达5亿美元总市值**"；"仅仅通过这一个公司的股票和权证……富达和它的客户们在1980年的收益就超出了**10亿美元**"；**方法论前置句**："一个能超预期发挥的公司，首先其**价值必须被严重低估**……如果市场上的流行观点都比你的观点悲观许多，那么你必须**不断核实真实情况**，确保自己没有盲目乐观"；"事物总在不断变化着，不是变得更好就是变得更坏，而你必须**紧随变化适时调整策略**"（"老房利美给人留下的糟糕印象还历历在目，人们看不见正从眼前崛起的新房利美"）。

**（1）商业模式与老房利美的病症（1801–1806行）**：1938年成立、1960年私有化；功用为"为房贷市场提供流动性"，方式是"从银行或储贷社购买抵押合约"；座右铭"**短借长贷**"——"以相对较低的利息借入资金，然后用它们买入抵押合约长期持有，并收受较高的固定利息，从中赚取差价"；**致命点**："这种运作策略在利率下降的时候效果较好……但是后来利率上升了，资金借入的成本随之上浮，房利美亏损严重"；作者1977年以**5美元**首次买入、"几个月后就抛空了"（"我看到利率正在往上涨"）；1981年困境：长期抵押合约收益**8%~10%**而短期贷款利率冲高至**18%~20%**，股价从1974年的**9美元**跌到**2美元**。

**（2）转型的三条主线（1808–1834行）**：**
①**更换管理层与新目标**：1982年启用**戴维·马克斯韦尔**（"希望采取措施有两条：①**停止'短借长贷'**；②**模仿'房地美'**"）；②**打包业务（证券化）**：把抵押合约捆绑成"**住房抵押担保证券**"出售给银行、储贷协会、保险公司、大学或慈善机构——"通过出售这些抵押权，它把**利率变动的风险转嫁给了新买主**"，并形成一个可即时交易的市场（"它的目标却是形成年营业额**3000亿美元**的庞大行业，比巨无霸的钢铁行业、煤矿行业和石油行业还要庞大"）；③**"凿刻花岗岩块"**：逐步置换70年代中期高价买进的旧抵押合约——1983年仍持有**600亿**这类不良房产抵押权，"平均收入9.24%的利息，但付出的平均成本却高达11.87%"。
**成本与融资优势（1819–1821行，可复算）**："银行的一般管理费用要占到**2%~3%**，房利美只需支出**0.2%**"；"它的整个薪金名册仅仅围绕分布在4个城市的4栋办公楼里的**1300名员工**"（"美国银行拥有的支行和房利美拥有的职工一般多"）；**准政府机构的融资利差**："它可以借到利息为**8%**的15年期贷款，然后用这笔资金购买利息为**9%**的15年期住房抵押合约，从中赚取**1%**的差价"——"美国其他银行、储贷协会或者金融公司都不可能依靠1%的差额获得利润。……但是**额度为1000亿的贷款的1%的差额仍然有10亿美元之多**"。

**（3）逐年推进与关键判据（1835–1882行）**：

| 年份 | 关键事实 | 价格/每股收益 |
|---|---|---|
| 1984 | 仓位0.1%→0.37%；利率升高收益下挫；开始发行**3年、5年、10年期债券**（"增加了房利美的资金成本，损害了短期收益"，但"可以少受利率波动的影响"） | `9→4美元`；每股亏损**0.87美元** |
| 1985 | 每年打包**230亿美元**（是1983–1984年的两倍）；发现新风险（**得克萨斯州**储贷协会乱放贷、"钥匙留在门上"）；5月拜访公司与马克斯韦尔交谈；仓位达**2%**进入十大重仓 | 每股盈利**0.52美元**；`4→9美元` |
| 1986 | 售出**100亿**"花岗岩块"（剩300亿）；"**即使只考虑公司的住房抵押担保证券业务，它的股票也值得买进**"；**强化贷款标准**（"让贷款的申请变得困难重重"，与花旗的无文档/弱文档按揭相反）；华尔街仍悲观（蒙哥马利证券称其"与一般储蓄银行相比已经有所高估"） | 每股收益**1.44美元**；最后5个月`8→12美元` |
| 1987 | 仓位**2%~2.3%**；得克萨斯房产没收使其成为"**得克萨斯州最大的房产巨擘**"、38名雇员专责销售；**10月大回落**；10月13日马克斯韦尔："**如果利率上涨3个百分点，房利美的收益只会下降50美分**"（"这是和以往划清界限的分水岭"）；90天逾期率在下降；股灾后公司宣布**回购500万股** | `12→16→12→16→8美元`；每股收益**1.55美元** |
| 1988 | 仓位约**3%**；严格新标准下发放的贷款已占组合**60%**；房产没收储量**首次下降**；**新会计准则**（还贷费用按每笔按揭生命期平均分摊，取代"还款到账即计收入"）→"自这些法规生效后，房利美再没有哪个季度收入突然严重下降过" | 每股收益**2.14美元** |
| 1989 | 巴菲特持有该公司**220万股**；得克萨斯问题"**得到了彻底解决**"、休斯敦房价上涨；《国家住房抵押贷款拖欠情况调查》显示90日拖欠率`1.1%→0.6%`；**"塞满货车"**：仓位达4%并一度到**5%的上限**（"我前所未有的最大投入"） | `16→42美元`（**一年2.5倍**）；打包规模**2250亿美元**、该业务利润**4亿美元** |
| 1990 | 维持5%上限（一度因股价上涨达**6%**，"这5%的限度被打破是因为股价上涨所致，不是因为我买进了更多股票"）；海湾战争引发"全国性房产市场衰退"的恐惧；"房利美公司的贷款拖欠问题现在已微不足道，但仍然因为人们**残存的记忆**而备受责难"；公司**从未批准过高于20.2万美元**的住房抵押贷款、平均额度**9万美元** | `42→24→38美元` |
| 1991 | 作者离开麦哲伦，继任者莫里斯·史密斯延续该持仓 | `38→60美元`；公司收入**11亿美元** |
| 1992 | 连续**6年**推荐；发行**可赎回债券**以降低利率风险（短期因票息更高而受损）；增长率**12%~15%**，"股价仍然被低估" | `69美元`、每股盈利**6美元**、**PE 11倍**对市场平均**23倍** |

**（4）本章的"好公司长期持有"论证（1851–1853、1866行）**："好公司的股票永远值得珍藏"；作者的极限情景推理——"经济会从短暂的衰退变成持久的萧条？要是那样，利率会下降，房利美可以以较低的短期利息率再筹得负债资金，从而受益。**只要人们继续支付按揭贷款，房利美公司就会是这个星球上留下的最后一个有利可图的公司**"；"人们愿意放弃（显然，休斯敦除外）的最后一样东西就是他们的房子"；以及**耐心与回报的时间结构**："正如股票市场上经常发生的那样，**经过几年的耐心等待，在一年中获得了全额的回报**"。

## 3. 复算（`阅读记录/B06_CH18_复算.json`）

1. **融资利差的规模效应**：`8%借入→9%贷出＝1%`；`1000亿×1%＝10亿美元`✅（作者的规模论证）。
2. **管理费用对比**：房利美`0.2%`对银行`2%~3%`→低**10~15倍**；员工`1300人`对"美国银行拥有的支行和房利美拥有的职工一般多"（**支行数与员工数直接类比的表述**，登记为口径随意的修辞）。
3. **老房利美的负利差**：`借入18%~20%`对`贷出8%~10%`→**−8%~−12%**；1981年"每股从9美元跌到2美元"＝**−77.8%**。
4. **"花岗岩块"的规模**：1983年持有**600亿**、1985年"售出100亿（1986年笔记）剩300亿"——**两次记述的基数差异**（600亿→300亿）与"1986年再次卖出100亿"并存，登记为**叙述口径需并列**（`PASS_WITH_CAVEAT`）。
5. **打包业务**：1983年"每月10亿"（年化120亿）→1985年"230亿"→1989年累计**2250亿**、该项利润**4亿美元**；1990年代目标行业规模**3000亿**。
6. **利率敏感度**：马克斯韦尔"**利率上涨3个百分点，收益只下降50美分**"——对照1987年EPS`1.55美元`，即**−32.3%**（单点陈述，未给传导细节，`BOOK_CLAIM_UNVERIFIED`）。
7. **价格与估值**：`5(1977)→2(1981底)→9(1982)→9→4(1984)→9(1985)→12(1986)→8~16(1987)→42(1989)→24~38(1990)→60(1991)→69(1992)`；1992年`每股6美元/69美元＝PE 11.5倍`（书称11倍）对市场23倍；1985年"如果EPS达7美元，则PE为1倍"（`9/7＝1.29倍`，书称"1倍"为约数）。
8. **90日拖欠率**：`1.1%(1988)→0.6%(1989)`（**−45.5%**），作者以其下降作为"度过最糟时期"的证据。

## 4. 疑点登记

1. **`BOOK_CLAIM_UNVERIFIED`**：员工/利润对比、5亿美元头仓与"10亿美元收益"、"2亿美元投资获6倍收益"、打包规模与利润、3000亿行业规模、150亿西南抵押敞口、185亿/2250亿、房价与拖欠率数据、巴菲特220万股、回购500万股、可赎回债券等——**全部为书内自述或转引**。
2. **`PASS_WITH_CAVEAT`**："花岗岩块"规模的三处叙述（600亿→300亿→再卖100亿）未被逐一勾稽；1985年"PE 1倍"为约数；"美国银行拥有的支行和房利美拥有的职工一般多"为修辞式比较。
3. **须加限定的强表述**："只要人们继续支付按揭贷款，房利美公司就会是这个星球上留下的**最后一个有利可图的公司**"——**极端情景下的修辞**，不构成估值或安全边际依据；"好公司的股票永远值得珍藏"须与§14退出纪律并行（作者本人也多次减仓与回补）。
4. **会计政策变化的影响**（1859–1860行）：新准则使还贷费用按按揭生命期分摊，"自这些法规生效后，房利美再没有哪个季度收入突然严重下降过"——**该改善来自会计政策，须与经营改善分开**（与§9.2的会计变更核查一致）。
5. **制度性优势的边界**："准政府机构"的融资成本优势是本案例的**核心前提**，其可持续性依赖**制度与监管**，不构成可外推的一般规律。
6. **仓位与限额的边界**：5%为SEC规定的基金单只上限；"因股价上涨达6%"不构成买入授权（与§6.2一致）。

## 5. 与其他书/框架的关系

- **与 B06第15章**：本章是"**周期股去周期化**"的完整样本（从"短借长贷"的利率赌注→证券化与资产负债匹配），呼应第15章"资产负债表优先"。
