## 2. 论证推进

**主张一：杠杆带来的增长是风险，不是可付费的价值。** 当企业部分以债务融资时，普通股股东须先清偿债务再分享企业价值。杠杆放大经营结果：好时更好，坏时更坏（以雷曼兄弟2008年股东归零为例）。因此"付费购买杠杆创造的成长"是本章反复警示的陷阱。

**主张二：权益要求回报是经营回报加杠杆溢价，且有固定因果方向。**
`r_Equity = r_Firm + (Value_Net Debt / Value_Equity) × (r_Firm − r_Net Debt)`。重排后得到WACC形式`r_Firm = (E/V) × rE + (ND/V) × r_ND`。作者明确：**第一式才是因果式**，WACC只是代数重排；用市场价格替代价值计算WACC时若不区分价格与价值会产生误导。

**主张三：融资无关性（Modigliani–Miller）。** 按公允价值发行或赎回债券、发行或回购股票都是零净现值交易：得到的价值等于放弃的价值。以剩余收益演示：按面值买入1,000元、要求回报5%的债券，年利50元，`RI = 50 − 0.05×1000 = 0`；若该债券由本企业发行，股东角度看`RI = −50 − 0.05×(−1000) = 0`。**只有交易价格偏离价值时融资活动才改变股东价值**（如以4,000万买断价值5,000万的1/3股权，剩余每股价值由5,000万升至5,500万）。

**主张四：必须先把法定报表重构为经营/融资两张表，杠杆才可见。**
`普通股权益 = NOA − 净债务`，其中`NOA = 经营资产 − 经营负债`，`净债务 = 债务义务 − 债务资产`。GAAP与IFRS都把经营与融资混在一起，不重构会漏掉杠杆。

**主张五：杠杆可用四种口径度量，各自用途不同。**
账面（资产负债表）杠杆`= 净债务 / 普通股权益`；收入表杠杆`= 净融资费用 / 净利`（其倒数近似利息覆盖的股权版）；市场杠杆`= 净债务 / 权益市场价`；收益杠杆`= 净融资费用 / 经营利润`（用于增长杠杆方程）。作者特别警告：**市场杠杆会随股价高估而被低估**，从而掩盖真实杠杆风险。

**主张六：ROE 由经营回报、杠杆与经营利差三因素决定。**
`ROE = RNOA + LEV × (RNOA − NBC)`，LEV取**期初**净债务/权益。零杠杆时ROE=RNOA；正杠杆且`RNOA > NBC`时ROE被放大；利差为负时（"不利杠杆"）ROE低于RNOA。作者结论：**评价价值创造应看RNOA，不看ROE。**

**主张七：杠杆污染一组会计指标，其中最反直觉的是P/E。** 杠杆**提高**预期收益增长与EPS（回购尤甚），但**降低**P/E。常见说法"杠杆提高P/E"是被证否的Teaser答案。相应地有E/P与P/B的杠杆方程。作者给出的应对是**未杠杆（企业）估值**：把债务的零剩余收益剥离，得到经营价值后减净债务；股价隐含的增长由此变为业务增长，且不必逐期重算变化的rE。

**主张八：真能创造价值的融资交易很少。** 回购价低于价值增加留存股东价值，高于价值则毁损（作者称回购高价"并不罕见"）；"回购以反向稀释"的辩护在不低于公允价值时才成立，1990年代高价回购反而加重稀释；债务套利（低息发债后低价回购）与"先发债压低债券价格再赎回"（损害债权人）属于例外情形，后者提示股东与债权人利益冲突，需看契约保护。

**主张九：价值投资者总体回避杠杆**，唯一可考虑的情形是确信股票低估时——此时可直接买入已带杠杆的低估企业，取得与私人加杠杆相同的上行空间；若认为股价便宜但公司杠杆过高，可考虑买入其债券对冲（属主动风险管理，留待第8章）。

**条件与反例。** 净债务可为负（微软2023年为−48,882百万美元，属净债权人），此时ROE低于RNOA、收入表杠杆为负、"杠杆提高ROE"的说法不适用，应改用其倒数解释；若净债务为正而经营亏损，标准杠杆指标无法计算，须用倒数且注意"负数表示杠杆更高"。作者也承认，Banks以利差"赚钱"与债务套利者寻找错价债券是融资活动创造价值的例外。

## 5. 疑点与未解决项

**5.1 契沙皮克表5.6存在30的勾稽冲突（书内冲突，待原披露核对）。** 表内`Operating LOSS after tax`印为14,552，但`18,919 − 4,397 = 14,522`；且`14,522 + 113（税后净利息）+ 171（优先股股息）= 14,806`正好等于表内`Net LOSS to common equity`，而`14,552 + 284 = 14,836`不等。反向验证：用14,552复算ROE杠杆式得−97.97%，用14,522得−97.78%，书内结论为−97.77%。**结论：表中14,552应为14,522**，但须查2014年10-K确认，未核前不当作已修正。

**5.2 契沙皮克年份标注不一致。** 表5.3、表5.6与第4802行标题均为2014年，但第4902行文字写"Chesapeake, 2015"。

**5.3 微软NBC显示符号与方程代入不符。** 按书内定义`NBC_t = NFE_t / ND_(t-1)`，微软`NFE=−995`、`ND=−41,251`，NBC应为**+2.41%**；书内图像显示为`−995/41,251 = −2.41%`（对净债务取了绝对值），而ROE杠杆方程括号内实际代入的是`56.96% − 2.41%`，即+2.41%。用+2.41%可精确配平到书内43.45%，用−2.41%不成立。属显示符号约定问题，不影响结论。

**5.4 有效税率18.82%的分子分母不同口径。** 书内将该比率标在`16,659`一行：`16,659/88,523 = 18.82%`（分母为未重述的法定营业利润）；若用重述后营业利润88,025，则为18.93%。两数都保留，注明分母。

**5.5 Micky Mouse Corp.回购后表的"剩余收益(15%)全为0"与固定折现率不自洽（自行推算）。** 表内保持`rE=15%`不变，但净债务按5%、NOA按10%增长，杠杆由1.0逐年下降，ROE由15.0%降至13.9%。按15%与表内数据复算，第1–4年剩余收益约为`0 / −0.25 / −0.54 / −0.87`（百万美元），并非全为0；若严格按15%折现，价值会低于账面50。书内"每股价值10元不变"是近似演示，其严格成立条件是每期重算变化的rE（作者在第5349行也承认"rE changes each period as leverage changes"）。

**5.6 微软无增长估值的舍入级差异。** `74,785/0.0777 = 962,484`，加账面206,223得1,168,707，与书内显示的1,169,148相差441（0.04%）；支付后`77,088/0.0801 = 962,396`，加156,223得1,118,619，与书内1,119,148相差529（0.05%）。属rE四舍五入到小数两位所致，结论（前后价值不变）不受影响。

## 6. 与其他书、框架的关系

- **与B02第3–4章一致且递进**：第3章建立重构账簿与剩余收益，第4章把价格拆为会计锚与增长；本章把"增长中来自杠杆的部分"从可付费价值中剔除，属同一逻辑的必要补全。第4章的杠杆隐含g因此是**含杠杆**的增长，本章提供去杠杆化的反推口径。作者立场与本框架选择一致：仍保留一致口径DCF作情景工具，不宣称作者认同DCF用法。
- **与B12（张新民）互补但口径不同**：B12关注合并/母公司差额、NCI上划限制与"两头吃"（经营性负债），本章把它统一进"净债务=融资性债务义务−债务资产"，明确**经营性负债（应付账款、预收、应计薪酬）属经营负债，不计入净债务**，两者不能混成一个债务率。
- **与B01（Schilit）互补**：租赁表外化（2017年前）属典型的杠杆隐藏手段，与第7类"关键指标误导"呼应；本章给出的处理（全部租赁计入净债务）正是对应的法证动作。
- **与B09/B03一致**：个人层面"不因市场高估而误以为杠杆低"与两者关于风险不因价格上升而消失的论述一致。
- **作者观点 vs 框架选择**：作者"价值投资者一般回避杠杆"是经验性主张，本框架把它转成"杠杆独立成一门"而非禁止持有带杠杆企业；回购创造价值以折价买入为前提，本框架不设机械回购阈值。
