## 2. 论证推进

**主张一：现金流对"持续经营估值"不重要，对"流动性与违约"极其重要。** 前十二章反复说"自由现金流不是增值度量"；但企业**借钱来杠杆化盈利增长**，若那些现金流未实现，就难以履行债务义务；违约时股东把控制权交给债权人、通常损失全部。这是杠杆风险的最坏情形，并**叠加第8章的久期风险**——即使现金最终会实现，偿债时点可能先到。因此股东除了经营风险，还要评估**违约风险**（债权人当然也要）。流动性在LBO（按期偿债）与PE基金赎回（按承诺日赎回）等情形下即使不违约也关键。

**主张二：现金守恒方程是一切流动性账簿的设计基础。**
```
FCF = C − I = d + F
d = 净股利 = 现金股利 + 回购 − 发行；  净债务 = 债务义务 − 债务资产
C − I = d + FO + FA      （FO：偿付债务义务的现金；FA：投入债务资产的现金）
违约点：FO > C − I − d − FA
```
含义：经营产生的净现金流在股东与净债权人之间分配；**若FCF为负，必须由股东（减少派现或增发）或净债权人（举债或卖出债务资产）补上**。CFO的替代手段清单（按可行性排序）：变现债务资产 → 削减股利/回购 → 增发 → 减少投资 → 出售资产；否则违约，由破产管理人出售资产。困境中增发会毁损股东价值（且可能无人接盘），困境中举债同样未必有人接。

**主张三：现金"烧钱"直接推高违约风险（vignette）。** Carnival（2020年债务义务283.80亿→2021年346.07亿、EPS −8.46/−6.31、经营现金流−41.09亿、FCF −103.36亿）、Royal Caribbean、以及BBBY（经营现金流由+3.27亿降至+0.68亿、FCF由+6.79亿转为−2.82亿；靠13.53亿资产出售与4.40亿债务资产补充）。"**只有退潮时才知道谁在裸泳**"；BBBY于2023年5月申请破产。

**主张四：GAAP/IFRS现金流量表必须重构（三项修正）。**
1. **经营段含利息收付**：除银行等利差业务外，利息属于融资活动，应移出并按税后口径调整：`（已付利息 − 已收利息）×（1 − 税率）`。BBBY 2022年：64.7 × (1 − 23%) = 49.8 → 修正后C = 17.9 + 49.8 = **67.7**；2021年：268.1 + 59.2 = **327.3**。
2. **投资段含债务资产净投入**：那不是经营产生的现金，会**少报投资现金支出、虚增FCF**（这正是最有害的一项）。BBBY 2021年清算3.865亿，剔除后投资段由737.9调整为**351.4**；与修正后的C相加得该年FCF = **678.7**（困境企业投资段在"产生"现金）。
3. **现金本身的变化**属于债务资产（现金等价物）的买卖，应归入融资段（2022年−9.363亿；2021/2020年为把盈余现金投入债务资产）。
修正后格式：`C − I = d + i + P`。

**主张五：司库规则（Treasurer's Rule）。** `若 C − I − i > d，则买入债务（P）；若 < d，则卖出债务`。Delta 2020年（困境）：C −3,077、投资段＋3,359（出售投资）→ FCF **−6,436**，税后净利息716 → 可分配 **−7,152**，净股利604 → **司库须筹资7,756**；实际动作：发债283.57亿、偿债85.59亿、买入债务资产120.42亿（"雨天"资金），净额 283.57 − 85.59 − 120.42 = **75.56亿** ✓。微软2020年（非困境）：C 605.81亿、投资192.03亿 → FCF **413.78亿**，税后净利息收入0.94亿 → 414.72亿；董事会派现151.37亿、回购229.68亿、员工发行回款−13.43亿 → 净股利367.62亿 → 剩余**47.10亿**用于"交易债务"：偿还债务89.35亿、出售债务资产42.25亿（89.35 − 42.25 = 47.10 ✓）。

**主张六：前瞻性流动性账簿用会计方程"自动"推出关键量。**
```
自由现金流 = 经营利润 − ΔNOA          （BBBY：2022 −510−(−228)=−282；2023 −943−(−515)=−428；2024 125+217=342）
净债务_t = 净债务_(t−1) + 净利息_t − (FCF_t − 净股利_t)   （2023：2,665+49+428=3,142）
权益_t = 权益_(t−1) + 盈利_t − 净股利_t                  （2023：174−992−0=−818；且 NOA − 净债务 = 2,324−3,142 = −818 ✓）
```
**不必直接预测自由现金流**——从重构资产负债表与利润表的预测中"掉出来"，而且有完整性校验（比EBITDA或"经营现金流−资本开支"更完整）。BBBY的前瞻账簿显示：2022年可偿债现金15 vs 需偿15（"否"）；**2023年 −77 vs 需偿699（违约）**；2024年 286 vs 需偿346（违约）；唯一可用的是最高**10亿**美元授信额度（但那是新增债务）。**根本问题是能否产生经营利润与现金流——那是偿付能力（solvency）而非暂时流动性**，后来JPMorgan向公司发出违约通知。

**主张七：违约预测的度量与"资产负债表 vs 利润表"的选择。** 指标：持续低利润或亏损、经营现金流与FCF下滑，加上第5章的杠杆度量——
```
资产负债表杠杆 = 净金融债务 / 普通股权益   （＝ NOA/普通股权益 − 1）
利润表杠杆   = 净金融费用 / 净利润
```
可加权成单一违约概率分数（**Altman Z-score、Ohlson O-score**）。**Jack in the Box**案例说明选择问题：2022年3月收购Del Taco后把门店卖给加盟商，目的是"把资产移出账面以获得更低成本的担保债务"——因为**以收入流为担保的债务被认为比以资产为担保的更安全**，于是**"资产负债表杠杆 vs 利润表杠杆"哪个合适**变得关键，尤其对"资产轻化"的公司。收入端度量还可细化（如加盟权使用费/担保债务、更好的是**预期未来权使用费/债务**）。

**主张八：原则收束。** ①自由现金流对持续经营估值无关，但对流动性与违约概率重要；②会计账簿监控流动性；③前瞻账簿预测违约；④司库规则支配债务融资。Case 21要求评估Delta在疫情期的违约可能性（多数美国航司历史上都进过破产）。

## 5. 疑点与未解决项

**5.1 BBBY 2020年列的修正不自洽（书内冲突）。** 表13.2 列 2020年 C = **640.8**，但按同一修正规则（经营段剔除税后净利息 55.8）应为 590.9 + 55.8 = **646.7**（差**5.9**）；而该列融资侧的税后利息取了 55.8，若用 640.8 则 FCF = 630.7 与融资侧配平，说明**C 与 i 两项必有一项口径不一致**（可能包含未说明的其他调整）。2021与2022年两列完全配平，问题仅2020年。

**5.2 表13.1/13.2的符号约定需谨慎。** 现金流量表中"投资段"在困境年份为**正数**（出售资产），"increase of debt assets"为负号；重构表把现金变化与债务资产买卖一并归入融资段，与常见列报习惯不同，跨年比较时须保持同一口径。

**5.3 前瞻账簿是"演示用假设数"。** 作者明确 2023/2024 数字为 hypothetical（"in no way coming from diligent forecasting"），仅演示方法；实际使用须自建预测并标注来源分级（A/B/C）。

**5.4 "以收入流担保优于以资产担保"是案例转述。** Jack in the Box的解释来自公司自述，作者据此提出度量选择问题；该判断需以债务条款原文核对。

**5.5 违约分数（Altman Z、Ohlson O）未在书中给出计算细节。** 作者指向 Wikipedia/Investopedia；本书正文未提供系数与阈值，使用时须查原始文献，且**书中索引未收录 Altman/Z-score/Ohlson**（见第十四章笔记的索引核对说明）。

**5.6 外部披露未核。** BBBY（10-K现金流量表与债务附注）、Carnival/RCL、Delta、Microsoft、Jack in the Box 的数字均引自书内附表或报道，**未调取原始文件核验**；`original_report_verified`保持`false`。
