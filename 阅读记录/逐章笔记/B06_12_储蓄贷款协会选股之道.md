# B06 第12章 储蓄贷款协会选股之道

来源：B06《彼得林奇投资经典全集（共3册）》第一册《战胜华尔街》第12章，v2合并全文第 **1331–1413 行**（83行、9,196字符；1331行为书名页眉行、1332行为章题。**5次图像引用 / 2个图像文件**：`00016` 装饰图标×4、`00033` **表12-1**；本批已目视）。spine23（`index_split_022.html`）**无脚注链**，正文含**译者注2条**（《风云人物》与查尔斯·基廷，1407–1408行）。`original_report_verified=false`。

## 1. 论证推进

**（1）被恐惧笼罩的行业（1333–1336行）。** 开篇列举公众联想的四件事（"储蓄贷款协会解困援助需要所有纳税人共同负担**5000亿美元**；1989年以来破产倒闭的储蓄贷款协会有**675家**之多；各家储蓄贷款协会的公司高管奢侈浪费得惊人；美国联邦调查局正在调查**10000多件**金融诈骗案"），并对比两个形象——电影《风云人物》里节俭的银行家（吉米·斯图尔特饰）与"身陷牢狱中的前任林肯储蓄贷款协会主席查尔斯·基廷"。作者随即给出**反常识的对照**："用最基本的财务实力分析指标——**资本充足率**来衡量，实力最强大的银行JP摩根银行也只不过是**5.17%**，而高于这一水平的储贷机构全美就有**100多家**"（例：康涅狄格州新不列颠大众储蓄银行**12.5%**）；同时自我限定："只拿一个指标来跟这个大众储蓄银行进行比较，是有点离谱……不过我想表达的关键一点是，我们都听说储蓄贷款协会经营得非常糟糕，财务实力非常差劲，而**事实正好相反**"。

**（2）三类储贷机构（1337–1351行，本章的分类法）。** "诈骗钱财的大坏蛋、把好事弄砸的贪婪鬼和吉米·斯图尔特那种节俭型的老实人"。

- **诈骗犯**（1339–1343行）：完整拆解骗术模型——"假设是10个，每人出资10万美元设立一家'信神'储蓄贷款协会……用凑起来的**100万美元的股东权益**，再吸收**1900万美元的存款**，然后……发放约**2000万美元的贷款**"；用高利率＋著名证券公司推销＋**FSLIC政府担保**吸存（书内广告："利率高达13%，联邦储蓄贷款保险公司（FSLIC）提供担保"）；"股东权益每增加1美元，公司就可以再像前面一样，吸收19美元的存款，然后发放20美元的贷款"；"贷款前先扣佣金，所以从账面上来看……**盈利惊人得高**"——**这是"虚增权益→放大杠杆→再放贷"的自我循环**；终点是"最后大到有足够的财力去**贿赂会计师、审计师，收买银行委员会中有权有势的参议员和众议员**，还有足够的钱购买Lear喷气式飞机，在船上搞派对，甚至进口大象"；**关键的结构性提示**："除查尔斯·基廷等少数几家公司之外，大多数诈骗型的储蓄与贷款协会都不是股票公开上市的公司，而是私人所有。股票公开上市的公司有一套严格的审查制度，是这些诈骗公司的股东和高管根本无法忍受的。"
- **贪婪鬼**（1345–1348行）："死水一潭"储蓄公司的故事——跟风请来"吊带裤先生"，"**最大限度地借款**，直接从联邦住房贷款银行借款……做一些能赚大钱的商业项目贷款"，并"投资入股这些房地产开发项目"；结果"经济萧条来临……那些本来要租赁办公大楼、公寓或购物中心的租客一夜之间消失得无影无踪"→"花了**50年**才积累起来的财富，却在**不到5年**的时间里就蒸发得干干净净"；作者点出它与骗子的区别："只不过死水一潭储蓄公司的董事并没有向亲友发放贷款，也没有暗中拿回扣装到自己的腰包里"。
- **老实人**（1350–1358行）：特征为"从邻近地区吸收存款，只进行**传统的购屋抵押贷款**"、"只维持简单的营运方式"、"**不会大把花钱把办公大楼修得像希腊神殿一样富丽堂皇**"；**成本口径（本章最可计算的一段）**："大型金融机构，如花旗银行，其**一般管理费用及其他相关费用，大约是贷款总额的2.5%~3%**。因此要保持盈亏平稳，存贷利差就得超过**2.5%**才行"；"但老实本分的储蓄贷款协会经营成本低……**存贷利差缩小到1.5个百分点左右照样能够维持盈亏平衡**"；并给出理论下限："向储户支付的存款利率为4%，而存款投资6%的国债，这样就有**2%的利差**"。
- **本章模范样本：金色西部储蓄贷款协会**（奥克兰，3家分支机构，赫伯·桑德勒与玛丽昂·桑德勒）：不碰"高风险垃圾债券或房地产商业投机项目"；"到现在也没安装自动柜员机"、"从来不用烤箱、冰桶等奖品来引诱客户存款"；"坚持固守于传统的住房抵押贷款，这项传统业务占其**贷款总额的96%**"；总部"选在租金低廉的奥克兰地区……前台**只有一部黑色电话**，客人来访得自行通报"；但"在各分支机构营业网点的装修上……一点也不吝啬"，并"经常派人**假扮客户**，暗中调查各分支机构的服务质量"。
- **一个制度性细节（年会）**：玛丽昂·桑德勒在西弗吉尼亚储贷协会年会上讲《经营效率与成本控制》，"与会的储蓄贷款协会高管中却有**1/3中途离席**。他们不愿听关于如何压低成本的演讲，却蜂拥到另一个房间去听一场关于最先进的电脑系统和计算器的演讲了"→"如果当时那些人肯用心听……或许他们中的大多数人现在还能留在这一行里"。

**（3）转制上市潮与作者的买入理由（1359–1361行）。** 80年代中期"有**几百家**原来是私人持股的储蓄贷款协会，转型为'共同储蓄银行'（mutual savings banks）申请股票公开上市"；作者在圆桌会议上说"我收到**145家**储蓄贷款协会的招股说明书，结果买了其中**135家**公司的股票"，主持人反问"那几家你不买的是怎么回事？"。**两个买入理由**：①"麦哲伦基金规模非常庞大，但储蓄贷款协会股本很小……这跟**鲸鱼必须大口蚕食浮游生物**才能生存一样"；②"储蓄贷款协会股票上市方式十分特殊，这使它们的股价从一开始就明显低估（要想知道如何花一分钱就能得到好东西，请参见第13章）"。
**行业结果统计（SNL证券公司）**："自1982年以来陆续上市的**464家**储蓄贷款协会中，有**99家被大型银行或大型储蓄贷款协会收购**，股东往往都因此大赚一笔（最明显的例子是**新泽西州莫利斯县的储蓄银行，1983年以10.75美元上市，3年后以每股65美元被收购**）；有**65家**股票公开上市的储蓄贷款协会破产倒闭……目前继续经营的还有**300家**"。

**（4）背景：房地产恐慌与覆盖真空（1364–1368行）。** "当时大概有两年时间，整个美国都在担心害怕一件事：房地产市场即将崩盘"；作者用住宅建筑商协会数据反驳（"二手房价格在1990~1991年连续上涨"），并指出"那些老实本分的储蓄贷款协会对高档住宅和商业不动产或房地产开发的贷款十分有限，其贷款大部分集中于**10万美元左右的住房抵押贷款**"。
**覆盖真空的量化（作者的"反指"）**：富达储贷精选基金规模"1987年2月为**6600万美元**，到1990年10月竟只有**300万美元**"；富达两位专职分析师一走后未补（另一位被调去研究房利美、通用电气与西屋电器）；"全美国只研究沃尔玛百货一家公司的分析师大概就有**50位**之多，追踪菲利普-莫里斯一家公司的分析师有**46位**之多，但研究公开上市的储蓄贷款协会股票的分析师一共只有**几个人**"→ **第18条林奇投资法则**：「**分析师都感厌烦之日，正是最佳买入之时。**」
**研究工具**：《储蓄贷款协会行业投资指南》（The Thrift Digest，SNL证券公司出版、里德·内格尔主编），"差不多跟波士顿这个大都市的电话簿一样厚，每年要支付高达**700美元**的订费"。

**（5）评估储贷协会的九项指标（1373–1393行，本章的方法核心）。**

1. **股票市价**；2. **首次公开发行价格**——"股价已跌破发行价，这是股票可能被低估的一个信号"；
3. **资本充足率**（"**最重要的分析指标**，代表公司的财务实力和生存能力"）——"最低的只有1%或2%（这样的股票跟废纸差不多了），最高的可能有20%（相当于摩根银行的4倍）。**一般平均水平在5.5%~6%之间，低于5%的话表明你投资的是一家有相当大风险的金融机构**"；**作者自定标准：不低于7.5%**，理由有二——"不仅表明破产倒闭风险很低，而且表明这种公司**有可能成为其他金融机构的收购对象**。因为这种公司**资本越充足，贷款放大能力就越强**"；
4. **股息**；5. **账面价值**——"如果储蓄贷款协会没有高风险贷款，那么资产负债表上的账面价值就真实反映了这家公司的实际价值"；
6. **市盈率**——"有些储蓄贷款协会每年收益增长15%，但根据过去12个月的收益计算，市盈率只有**7~8倍**"，而"标准普尔500指数平均市盈率为**23倍**"；
7. **高风险不动产资产**——"尤其是商业贷款和建造工程贷款，成了许多储蓄贷款协会的葬身之地。如果一家储蓄贷款协会的高风险资产占总贷款的**5%~10%**，我就会十分害怕、担心"；**并给出可自行计算的方法**："先在年报的'资产'项目下找到**建筑及商业不动产贷款额**，再找到**对外发放的贷款总额**，用前者除以后者"；
8. **逾期90天贷款**——"最好不要超过**总资产的2%**，而且最好是持续下降而不是上升。有时不良贷款比率即使只是增加了一两个百分点，也可能使一家储蓄贷款协会的**所有股东权益化为乌有**"；
9. **抵押不动产处置**——"金额有多大，就表明过去贷款的问题有多大，因为原来发放的抵押贷款已经全部作为坏账损失冲销"；"因为已经列为损失，所以……**不会像高风险资产比例那么令人担心**"，但"若处置额持续上升，就十分令人担心"；并给出实务提示："储蓄贷款协会并不是房地产商……单是维修费用就非常高昂，想卖出去也很不容易"。

**（6）1992年推荐的7家（1395–1399行）。** "其中**5家属于财务实力稳健且经营老实本分的储蓄贷款协会**，另外两家则属于……**起死回生类型**"（**Germantown Savings**与**Glacier Bancorp**为1991年已推荐、现再次推荐）。
**5家的共同指标**："其中**4家股价低于账面价值**；**资本充足率都达到或超过6.0%**；**高风险贷款比率低于10%**；**逾期90天不良贷款比率都低于2%**；**收回抵押不动产比率低于1%**；**市盈率低于11倍**"，"其中两家最近**回购股份**"；"冰河银行和德国小镇储蓄公司商业贷款比率略高，不过听了公司方面的解释后，我认为问题不大"。
**2家起死回生型**："很多分析指标都相当糟糕……我之所以认为这两家公司股票值得冒险投资，是因为尽管存在很多问题，但它们的**资本充足率仍然保持相当高的水平**。有了充足的资本作为缓冲资金，就给了这两家公司相当大的回旋余地"；区域上"靠近马萨诸塞与新汉普夏的边界，这个地区经济已经显示出稳定的迹象"。
**必须并置的限定（作者自己的）**："**它们能不能生存下来，我可不敢保证。**不过它们的股价跌得实在非常之低（如**劳伦斯储蓄公司（Lawrence Savings）由13美元跌到只有75美分**），我认为抄底买入肯定能大赚一笔。"

**（7）收购逻辑与行业整合（1399–1404行）。** 被收购的吸引力来自三个条件："**股东权益相对于资产的比例非常高**，**贷款能力相对于存款有很大的扩大余地**，又有一个**非常忠实的存款客户群**"；制度原因是"商业银行**只能在所在的州里吸收存款**……但它们却可以向全国任何一个地方发放贷款"；极端样本是**楠塔基特岛家庭港湾储蓄银行（Home Port Bancorp of Nantucket）**——"资本充足率高达**20%**，这大概是当今世界上最稳健的金融机构"，客户群是"从来不会改变他们的存款习惯"的新英格兰人。
**整合的量化**："从1987~1990年……有**100多家**储蓄贷款协会被大型金融机构收购"；"目前整个美国的银行、储蓄贷款协会及其他各种存款机构，**总数超过7000家**，依我看来其中**6500家都是多余的**"；"仅仅是在我住的马布尔黑德小镇，就有**6家**不同的存款机构，而**整个英国只有12家**存款机构"。

## 3. 复算与口径（底稿：`阅读记录/B06_CH12_复算.json`）

1. **诈骗模型的比例**：`100万权益 → 1900万存款 → 2000万贷款`，即**权益/资产＝1/20＝5%**；"股东权益每增加1美元→再吸收19美元存款→发放20美元贷款"✅（倍数一致）。
2. **成本口径**：花旗等大型机构一般管理费用占**贷款总额2.5%~3%**→盈亏平衡需利差**>2.5%**；老实人型**1.5个百分点**即可；无贷款情形下限**4%存款→6%国债＝2%利差**✅（三个数字层级自洽：2%<1.5%~2.5%<2.5%~3%）。
3. **资本充足率量级的量纲提示**：JP摩根`5.17%`、大众储蓄银行`12.5%`、"高于5.17%的储贷机构全美100多家"、行业平均`5.5%~6%`、作者门槛`7.5%`、极端`20%（＝摩根4倍）`——`20/5.17≈3.87`，"4倍"为约数✅。
4. **SNL行业统计**：`99＋65＋300＝464`✅（与"自1982年以来上市464家"一致）；收购率`99/464＝21.3%`、破产率`65/464＝14.0%`；莫利斯县储蓄银行`10.75→65＝6.05倍`（3年折年化约82.3%）。

## 4. 疑点登记

1. **`PASS_WITH_CAVEAT`：表12-1中People's的逾期90天不良贷款比率为2.0%，与正文"逾期90天不良贷款比率都低于2%"的表述处于边界**（若按"不超过2%"理解则一致）。
2. **`BOOK_CLAIM_UNVERIFIED`**：救助成本5000亿美元、破产675家、FBI调查10000多件诈骗案、SNL的464家统计与莫利斯县案例、富达基金规模6600万→300万、分析师覆盖人数、7000家/6500家、英国12家存款机构、桑德勒夫妇的全部做法与金色西部96%传统贷款占比等——**均为书内自述或转引**。
3. **须加限定的强表述**："我认为**抄底买入肯定能大赚一笔**"（针对两家起死回生型）——同一段已自带"**它们能不能生存下来，我可不敢保证**"；本项目**以限定句为准**，不采纳"肯定"的表述。
4. **第18条法则的适用边界**："分析师都感厌烦之日，正是最佳买入之时"是**经验性反向指标**，本项目只作研究触发（须与基本面九指标并行），**不构成买入授权**。
5. **两类投资者的混用风险**：作者同时推荐"5家稳健型"与"2家起死回生型"，但两者的**证据标准与失败概率完全不同**（前者以指标筛选，后者以"资本缓冲＋区域企稳"下注），引用时不得合并为"7家储贷股"一个结论。
6. **表12-1的"＋/−"号含义**（分拆调整标记）在书内未逐项说明；引用具体价格时须注明该表为1991年第三季度数据、且有调整标记。
