## 2. 论证推进

**主张一：首要风险是"付得太多"；买入后的风险来自基本面而非价格波动。**
标准风险分析看beta与价格波动；价值投资者看驱动价值的基本面（销售、利润率、周转率）风险。"beta是对过去价格波动的度量，价格可变性——是的；风险——不是。"（ Buffett 1993）Klarman补充：把过去价格波动当成风险描述"荒谬"，价格水平本身被忽略。

**主张二：要求回报 = 无风险率 + 风险溢价，而无风险率含购买力风险。**
`r = (实际无风险利率 + 预期通胀率) + 风险溢价`。政府债券并非真正无风险：政府可通过印钞降低实际偿付（1970年代高通胀时美国国债被戏称"没收证书"）；2023年硅谷银行（美国第16大银行）倒闭不是因为坏贷款，而是因为持有的美国国债在通胀上升中贬值。持有到期的国债在**货币**意义上近似无风险，在**购买力**意义上不是；股票没有到期日，投资者始终暴露。

**主张三：P/E与P/B与利率、通胀负相关（图8.1四联图）。** 1960–2021年trailing P/E对10年期国债收益率与通胀率均呈下行关系，时序图同向。2022年：前瞻P/E由22.7降至18.9，10年债利率由1.52%升至3.88%，通胀8.0%，与第2章`P/E = 1/(r − g)`一致。通胀期间的价格下跌同时是名义与实际的双重损失（1960年代中期至1982年道指由1000跌至777，通胀调整后跌74%）；2022年前四个月通胀8.5%期间标普跌10.9%。

**主张四：久期风险。** 收益实现越远，受冲击的机会越多，要求回报应越高。2022年科技股（价格基于长期收益预期）大跌即为久期风险与利率/通胀风险共同作用。

**主张五：风险溢价同时取决于预期收益（Fama-Lintner比）。**
`r = 风险 / 预期收益`。同样风险下，预期收益100的投资优于50的。这与价值投资一致：低估企业的预期回报更高，承担该风险更值得。

**主张六：CAPM不可用，寻找"资本成本"是徒劳。**
四点保留：①无风险率不真无风险；②市场风险溢价不可知（2022年各国调查由瑞士5.2%到阿根廷17.7%、委内瑞拉19.4%——作者称之为"投机"）；③历史beta的标准误≥0.2（估值1.0时真值可能是0.8或1.2）；④正态分布假设不成立于经验。多因子模型（Fama-French等）同样失败。WACC需要rEquity（不可得）与权重（需要Value，而Value正是要求解的对象）；用价格替代价值会让WACC反映**错价**而非要求回报。**"计算价值来挑战价格时，不要把价格放进计算。"**

**主张七：要求回报是个人事务。** 2008危机vignette：教授（终身教职、低负债、安全组合）说"这是我买入的时候"，学生（学贷高企、就业前景不确定）几乎全都不买——同一价格、不同要求回报。启示：风险溢价"存在于观察者的心中"；应与配偶/伙伴商议门槛率，而不是与CAPM商议。引申的制度含义：若只有安全的投资者能在下跌时买入，财富会更不平等；基金门槛率应代表投资者的门槛率（例如以投资者门槛率作为业绩费的门槛而非按AUM收费）。

**主张八：分散化能降低风险，但嵌入陷阱。**
图8.2：随股票数量增加，组合标准差下降，约15只后趋平（Markowitz）。但股票间平均相关性约0.65，**下跌市场趋近1.0**：2008年股票、债券、油气与REITs相关性升至约0.95；2022年美国股票、国际股票、政府债券与地产同跌，"无处可藏"。上涨市场相关性下降（而那时投资者希望同涨）。极端分散（持有全市场组合）只能得到市场风险。Munger："投资的目标是找到不需要分散的场合。"

**主张九：风险在尾部，且两端都厚。**
图8.3：S&P 500 1973–2021年收益率分布对上正态曲线——左尾负收益比正态更厚，右尾大于25%的收益也更频繁（**注意图内与正文的标准差不一致，见疑点5.1**）。风险在两端：**下行风险由上行潜力补偿**。价值投资的落点：通过"买便宜"（价值>价格）获得上行尾部敞口，通过"避免高估与理解持有期风险"减少下行尾部敞口。个股的分布比指数更宽（可损失100%，也可能一年涨300%以上）。

**主张十：杠杆增加尾部风险，增长永远是冒险的。** 买航空有风险，买**杠杆化**的航空更危险（第5章）；破产的股东损失通常100%，根源是不能覆盖债务。第三个Teaser的答案：**"增长是冒险的"永远为真**。

**主张十一：除基本面风险外还有价格风险与信息风险。**
- **价格风险**：价格可继续偏离（1996年即有价值投资者卖出，却错过1997–1999年的33.4%/28.6%/21.0%与P/E超33；做空者遭遇追加保证金，印证凯恩斯"市场保持非理性的时间可以长于你保持偿付能力的时间"）。价格不仅由基本面驱动，也由"动物精神"与情绪驱动（行为金融，作者自认不专长，不展开）。应对：耐心（第1章第十条原则）；2000–2002年标普跌49%。
- **信息风险**：①他人信息更多（交易所匿名交易、内幕交易法难以执行、披露监管是对策；缺乏披露本身就是风险）；②**信息质量**（会计质量分析见第9–10章；审计只提供有限保证，GAAP与IFRS都有缺陷；内部人控制薄弱点如关联交易、客户资金混用、记录保存——2022年FTX与Celsius的案例）。信息风险要求**更高的门槛率**，极端情况下放弃。

**主张十二：基本面风险分析＝第7章驱动分解 + 敏感性分析 → value-at-risk 画像。**
把每个驱动情景沿分解树上推到剩余经营收益，形成一组估值："价值风险画像"。微软2023年（r_Firm = 8.5%）：
- 无增长价值 = 206,223 + 62,640/0.085 = **943,164百万美元**；
- 8个增长情景（−2%至6%）的值由802,794到2,711,823；
- 相对市价2,428,712的价值/价格比由33.1%到111.7%；
- **只有增长超过6%时价值才高于价格**（6%情景为111.7%）。
**这8个数值全部可由`206,223 + 62,640/(0.085 − g)`精确复算**（见第4节）。概率由投资者按对业务的理解赋值——"一个人不买股票，买的是企业；买企业就要懂企业"。作者提醒不要与用价格波动估计左尾的VaR指标混淆。

**主张十三：驱动结构决定风险画像。** Coke（利润率与周转率稳定）→风险主要来自销售；航空/无线运营商（固定资产与固定成本）→销售同时驱动利润率与周转率，风险更大。Delta 2019年案例给出两种下行情景：
- 无增长价值 = 15,358 + (0.1723−0.10)×29,731/0.10 = 36,854百万（当时市值37,546百万，即市场定价"无增长"）；
- 情景1销售降至43,000（费用不变）：OI 2,024、RNOA 6.81%、价值**5,874**；
- 情景2销售降至17,095（燃油3,176、客运服务323）：OI **−13,192**、RNOA −44.37%、价值**0**（负值受有限责任约束归零）——这正是2020年疫情冲击的近似情形，靠政府援助、政府债务担保与员工配合度过。
**上行就伴下行**：高经营杠杆与不可缩减的NOA同时放大损失。

**主张十四：安全边际的操作定义。** 在价格具备吸引力之后，**寻找下行概率低的情形**：如果上行潜力显著高于下行风险，就安心投资。同等当前驱动下，铁路（货运需求持续）优于航空；持续10%销售增长＋40%毛利＋20%营业利润率＋稳定周转的企业优于低增长薄利企业——**因为后者本身暗示对下行的敏感**。

**主张十五：会计传递风险与不确定性。**
- **公允价值会计**把投机放进资产负债表（P/B=1），风险只在"打到我们"之后才显现（1929、2008–2009银行）；价值投资者不接受。
- **实现原则**（应计会计的基础）：**不确定消除后才确认收益**。价格（恰当地）包含对未实现收益的投机，会计师不确认它们——这正是"这些收益仍有风险"的信号，因而应在折现中扣掉。
- 两个子原则：①**收入确认**（ASC 606 / IFRS 15：合同双方义务均已履行且收款高度确定）——已确认收入是"风险已解决"，未来客户的收入是"仍有风险的价值"；1990年代末大量无收入互联网公司被市场高估，价值投资者予以折价（多被证明明智）。②**投资费用化**（FASB No.2、IAS 38把研究费用化；广告与品牌、人力资本、供应链与分销、客户忠诚计划、未证明技术可行性的软件）：判据是"未来经济利益的可能性"。**谨慎的会计把风险传递出来**：高R&D/低收入的生物科技初创风险高，有成功记录的成熟药企风险低。作者提醒：风险传递不等于让投资者据此改写会计数字，而是**在设定门槛率时把该风险计入**。

**主张十六：投机性收入的代价（案例群）。** 1990年代末Amazon（拆股前>$400跌至$7.00，直到2014年才首次盈利）、Priceline（市值一度超过美国航空业总和，后被Booking收购）、Netflix（P/S>4、trailing P/E 36，2022年自高点跌70%）、Tesla（P/S 16、P/E>100，2022年自高点跌55%）、Rivian（2021年11月IPO至$172、市值1,530亿，仅交付156辆卡车，2023年6月底跌至$16.66，−89%）、Nikola（2022年6月$65.90→一年后$1.38）、Nvidia（2024年1–10月涨148.07%至$122.85，前瞻P/E 63，作者以问句收尾："这是投机还是理性定价？"）。
Twitter的估值结构最能说明"风险在远端"：`价值_2017 = 4,829 + (−957.36)/1.12 + (−874.3)/1.12² + 投机价值 = 31,389`（P/B 6.5），**投机价值约占价格的89.6%**；2021年收入增至50.77亿美元但R&D与营销仍占47%。

**主张十七：风险 ≠ 不确定性。** 风险＝已知结果状态空间与其概率（可计量）；不确定性＝连可能的结果集都不知道（黑天鹅：9/11、疫情封锁）。"我们买入的是不确定性，不是风险。"因此会计用**谨慎判断（heuristics）**而非概率分布来费用化R&D。

**主张十八：增长/回报画像（ERE）替代单一折现率。**
`ER_Firm = [NOA/P_NOA] × RNOA_1 + [1 − NOA/P_NOA] × g`（企业）；
`ER_E = [B/P] × ROE_1 + [1 − B/P] × g`（股权，且`B/P × ROE_1 = Earnings_1/P`）。
这是"加权平均预期回报公式"（勿与WACC混淆）：以账面价格比作权重把盈利能力和增长加权。它把"未知的g"变成情景变量——给定g即得买入后的预期回报，从而得到**回报-增长画像**（微软2023年；S&P 500在2021年末：前瞻ROE 21.46%、B/P 0.211）。
作者用1982–2018年数据检验：以4% GDP增长估计的ERE与随后1–5年实际回报的相关系数分别为0.268/0.341/**0.454**/0.480/0.517——**相关但不完美**（1999年底ERE 6.61%对应随后3年−14.5%/年；2008年底10.09%对应+14.0%/年；2011年10.44%对应+20.5%/年）。**高ERE也可能只是更高风险的定价**，须与宏观不确定性同读。
同一风险等级（按行业或按风险情景分析归类）内，应选ERE更高的公司；进阶做法是配对交易（做多占优画像、做空另一方），但做空有风险。

**主张十九：风险的管理与对冲。**
- **安全股票**：行业是粗略代理（2022年标普−18.1%时必需消费−2.7%、公用−0.5%、医疗−3.2%；但同业内Clorox −20%，而Campbell Soup +30%、General Mills +25%）。基本面风险分析才能识别真正的安全股票。
- **表8.1**（1981–2012，按基本面风险分十组）：低风险组有更高B/P以外的特征——更高已实现销售增长、利润率上升、SG&A/销售下降、R&D/销售下降、NOA增长；**高风险组的未来盈利增长更高，但那是"有风险的成长"**（盈利beta由0.45升至4.42）。Panel B：收益随风险上升（4.9%→28.2%），**下行beta由0.48升至1.45**，峰度由2.364升至5.782。启示：**低P/B策略可能只是买风险**。
- **表8.2**：安全股票在下跌市场的保护（2000–2002年−1.70% vs 市场−14.73%），代价是上涨市场收益较低（1995–1999年16.29% vs 27.75%）；**但2008年9月–2009年2月安全股票跌65.3%而市场跌50.5%**，随后2009年3–12月安全股票+95.1%（市场+45.7%）。
- **图8.5**：1967年起60/40（标普+安全股票）累积回报236.5%，60/40（标普+10年美债）149.5%，40/60（标普+安全股票）195.7%（至2021年），差异主要发生在2000年之后。
- **对冲不想要的风险**：燃料、汇率、利率等可用工具对冲（若公司未代投资者对冲）；保险有成本，且要警惕"大规模杀伤性武器"：英国养老金LDI（2022年规模约1.5万亿英镑，约英国GDP的三分之二）在2022年9月债价下跌中遭遇追加保证金，被迫折价抛售抵押品；英格兰银行介入购债，反转紧缩政策；与2008年CDS/AIG的教训并列。**即便工具非投机，也要警惕对手方风险。**
- **通胀对冲的六类特征**：①能提价而不增费（必需品或高进入壁垒，看毛利率及其通胀期波动）；②收取他人销售额一定比例（信用卡公司）；③低投入扩张（通胀期ATO上升）；④低折旧（历史成本购得的资产）；⑤固定利率债务（实际负担随通胀下降）；⑥可变利率债务资产（银行在加息中受益——2022年英国四大行）；反面是2022年的零售股（Walmart −6.8%、Target −24.9%、Home Depot −5.2%、Best Buy −10.5%）。个人可用"房地产＋固定利率按揭"复制银行的资产负债结构。

## 5. 疑点与未解决项

**5.1 图8.3的标准差两处不一致。** 图内标题印"Mean: 12.45 and std dev: **17.32**"，正文写"标准差 **17.16%**"。两者描述同一1973–2021年样本，须核原图数据。

**5.2 微软增长/回报画像的正文与表格不一致。** 正文称"5%增长对应8.71%、7%对应10.64%、每1%增长贡献0.965%"，而方框表格为5%→8.77%、7%→10.62%、边际0.93。且正文三个数字彼此也不自洽（8.71与10.64隐含B/P分别为0.0700与0.0714）。以方框公式`0.071×58.0% + 0.929g`为准。

**5.3 微软方框的市场价内部矛盾（恰差180,000）。** 方框列NOA市场价2,199,830、净债务−48,882、权益市价2,428,712；但按第5章的企业价关系应为`2,199,830 + 48,882 = 2,248,712`，与所列权益市价差**恰为180,000**。二者必有其一笔误，待核；此项直接影响B/P=0.071（若用2,379,830则为0.066）与全部ERE数值。

**5.4 S&P 500页方框的公式与表格不一致。** 公式写`0.211×21.46% + 0.789g`（g=0应为4.53%），而表格g=0为4.40%、斜率0.795 ⇒ 表格实际使用的是B/P≈0.205。标称输入与结果口径不符。

**5.5 Delta情景的税率口径。** 2019年有效税率=1,494/6,618=22.58%，但情景1、2的税后OI（2,024与−13,192）都对应**22.5%**的税率；差异约12百万（0.09%），属取整口径。

**5.6 正文单位与标签笔误。** 微软风险画像方框首行印"rFirm = **85.%**"（应为8.5%）；另方框内ReOI_2024取62,640（第7章为62,634.7，四舍五入到62.6十亿），两者口径一致但显示精度不同。

**5.7 表格抽取打散。** 表8.1 Panel A/B、表7.x式多列结构在抽取中被拆行；本笔记按列位复原并按10个组合逐项复算（B/P、销售增长、下降beta、峰度、Range/σ），但个别单元格仍建议以原表核对。

**5.8 外部研究与披露未核。** 表8.1、8.2与图8.4、8.5所依据的Penman-Zhu（2022，JAE）与Penman-Zhu-Wang（2022 SSRN / 2025 FAJ）论文、Compustat与FactSet数据、以及Case 13–15要求拉取的Amazon/Microsoft/S&P 500原始数据，均**未独立核验**；`original_report_verified`保持`false`。文中大量历史价格（Netflix −70%、Tesla −55%、Rivian −89%等）亦未核原始披露。
