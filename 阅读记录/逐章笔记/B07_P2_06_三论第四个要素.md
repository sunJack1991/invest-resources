# B07 第二部分第6章：三论第四个要素——公司评价与整体股价水准（543–559行）

## 1. 来源

## 2. 论证推进
- 公司评价（第三层）比行业评价更重要：评价越接近三要素标准，本益比越高。
- 反对简单数学比较：同样10%成长的公司在10倍与20倍本益比下“便宜”与否，取决于**杠杆风险、估计值受意外事件影响的敏感度**，以及最关键的——
- **成长持续性的差别**：两支同为本益比20倍、四年盈余翻倍的公司，若四年后一支仍被预期再翻倍（仍20倍→价格翻倍），另一支被预期成长停滞（降至10倍→价格不变），则**价格表现天差地别**。由此得出原则：“**未来盈余继续成长的可能性愈高，投资人负担得起的本益比愈高**”（同时提醒：本益比变化取决于金融圈相信什么会发生，而非实际发生什么）。
- 高价买入的额外风险：准确预测多年成长后，还需等待多年兑现；期间即使最优质公司也会暂时退步，此时“高成长已反映”的市场认知会暂时消失，悲观期尤其严重——耐性足够的投资人可从中找到低风险机会。
- **摩托罗拉案例（1974年3月13日）**：前一日收盘48.5美元（原文数字为OCR缺字），当日宣布把电视机事业与存货按接近账面价值出售给松下，股价单日约+75%（数字缺字）；机制不是亏损业务出表本身，而是**金融圈长期用“电视机公司”标签评价摩托罗拉**（标普指南仍写“收音机及电视机：半导体”），通讯事业部约占公司一半；有分析师报告单独衡量通讯事业部价值＝当时股价。随后数周股价回吐，作者归因于短期利率回升与空头市场心理，并强调抢进者未必做对（“稍有耐性等候还是对的”）。
- **价位区间锚定危险**：股票长期停留在某区间（如38–43美元）后，投资人会把该区间当作“价值”；跌到24美元便抢进、涨到50–70美元便抛售——两者都可能是错。真正的检定标准是**基本面显著高于或低于当前评价**，而非与历史价格的比较。
- 第三层评价的第二部分：**整体股市展望**。1927–1929“新纪元”（含融资买进）→大萧条；1946年中–1949年中反向错误（盈余好而本益比为本世纪最低，最终展开长期涨势）；1972–1974年空头市场的本益比水平与1946–1949同样低，是否合理留待后文。
- 影响整体股价的纯金融因素：**利率最重要**（利率升→资金流向货币市场、股价跌）；储蓄率影响较小；新股发行量的影响更小（本身受其他因素驱动）。
- 总结：个股价格由金融圈对公司、行业及整体股价水准的评价共同决定；判断是否具吸引力主要看**评价偏离事实真相的程度**，同时估计利率等纯金融因素的变化。
