# B05 第8章 会计政策

来源：B05《巴菲特致股东的信》（原书第4版）第8章，内部文件 `text/part0071.html`（部分）至 `text/part0075.html`，v2合并全文第 **2367–2423 行**（57行、5,297字符含换行；**无图**）。A–D四节及各节末尾注释逐条读完。`original_report_verified=false`。

## 0. A. 并购（2368–2385行）

- **两种方法**：GAAP 容许**购买法**（现金或股票皆可）与**权益合并法**（交易标的必须是股票）。管理层通常**排斥购买法**，因为账上会多出"商誉"科目并须分年摊销（可能长达数十年）；**权益合并法避免商誉及其摊销**，故受管理层青睐。
- **FASB 有意取消权益合并法**，遭许多 CEO 反对。作者**同意"商誉摊销常常不符合实际"**，但**认为 FASB 的坚持正确**：
  - **摊销规则与现实严重不符的机理**：大部分会计费用（折旧、存货跌价、坏账、保修准备）虽不精确，但**至少与现实方向一致**（实体资产必然减损）；而**经济商誉在许多情况下并不减损，反而随时间的累积而增加**——作者以**禧诗糖果为例，称"在过去的78年里，其品牌价值以不规则但快速的速度成长"，并称"只要我们经营得当，其品牌价值增长的态势会继续维持另一个78年"**。
  - **权益合并法的实质**：源自"两条河流汇流后不再分彼此"的概念，被购并的公司"并不算是被'买下'的（尽管它们通常会得到相当的合并溢价）"。
  - **作者的判断**："有点咬文嚼字"——"只要你问问交易双方的员工，谁是征服者，而谁又是被征服者，就知道是怎么一回事了"；**多数购并案确有买卖性质**，真正的"对等合并"概率"实在是少之又少"。
- **作者提出的替代方案**：①购并公司应**以公平市价列出其投资成本**（无论支付现金或股票），账上会出现大笔经济商誉；②**该资产继续保留在账上，不分年摊销**；③若经济商誉**真有减损**（"这不是没有可能"），**按一般判断资产减值的方式进行计减**。
  - 若获采纳预计**追溯适用**；作者预期其效果是**促使管理层更审慎地评估"用现金还是股票"，基于真实股东利益而非合并后的会计账面损益**。
- 注[1]="1999年。"；注[2]="参阅第6章D节：经济的商誉vs.会计的商誉。"

## 1. B. 分部数据和会计合并（2386–2393行）

- **1988年 GAAP 变化**：伯克希尔必须将**所有子公司的资产负债表与损益表合并**（此前互助储贷与斯科特·费泽金融只须"一次计提投资损益"：按比例显示投资权益与投资损益）。
- **作者的核心判断**：**"企业形态越复杂的公司，其按传统财务报表所加总出来的数字越没有意义，越没有办法让投资人回答前面所提的三个问题"**；**"在伯克希尔我们会准备合并数字的唯一原因就是要符合外部规定，而芒格和我看的则是另一套信息"**。
- **应对**：公布更多**补充信息**，"不一定会依照一般公认会计原则，甚至不会以公司来区分"，而是**把同性质的企业汇总在一起**，目标是"呈现给你们重要的信息，就像你我换位思考一样"。
- 注[1]="1988年。"

## 2. C. 递延税项（2394–2413行）

- **规则变动**：递延税计算规则的重大变动（原定1989年实施，延后一年）。
- **1990年规则的影响**：必须**重新计算保险公司持有未实现股票资本利得以计算递延所得税负债**。
  - 原分两层计提：**1986年以前**未实现收益约 **12亿美元** 按 **28%**；**1986年以后**约 **6亿美元** 按 **34%**（差异反映1987年起税率调整）。
  - 新规则要求自1990年起**全部按34%**；作者估算这将使年度盈余（及财报净值）**减少7,100万美元**。
  - **复算**：原计提 `12×28%＋6×34%＝5.40亿`；全按34% `18×34%＝6.12亿`；**差0.72亿＝7,200万美元**，与书示"7,100万"相差100万（舍入），**登记**。
- **作者的立场**：**不认为该规则有强烈必要性**——"不管税率是28%还是34%，都不能反映我们公司的实质现况，**因为我们从来不考虑出售我们具有庞大未实现利益的股票**"。
- **"无息贷款"比喻**：递延税项负债"就好像是美国财政部借给我们的**无息贷款**，而且**到期日由我们自己来决定**"（除非国会把课税时点提前到未实现资本利得之前）；其特点是**只能用于购买某些特定的、升值的股票**，额度随市价与税率变动；"事实上这种递延所得税其实有点类似于资产移转时所要缴纳的交易税"。
  - **数据**：若年底按市价出售全部证券，应缴税项**超过11亿美元**；**1989年只出售一小部分持股**，产生 **2.24亿美元** 资本利得，发生 **7,600万美元** 交易税（**复算 7,600/22,400＝33.93%≈34% ✅**）。
  - **作者的反问**（两项都为否）：这11亿负债"等于或是类似于……应付账款吗？当然不是"；"难道……因为我们从来没有意愿要把股票卖掉……就表示它不具重大的意义吗？答案很显然也不是"。
- **1993年新规则**：取消账上二分法，要求**以现行税率估计所有递延税项**（作者认为"这样的做法较合理"）。
  - 以 **1992年年底** 计，未实现收益高达 **76亿美元**（其中 **64亿** 按34%、**12亿** 按28%）；**复算 64＋12＝76 ✅**；新规则使净值**减少约7,000万美元**（**复算 `76×34%−(64×34%＋12×28%)＝0.72亿`，与书示"7,000万"相差200万，登记**）。
  - 未来税率变动时须**立即调整**递延税负债与净值；但"真正重要的是……最终出售证券、由'未实现'到'实现'时所适用的税率到底是多少"。
- 注[1]="1988年，1989年，1992年。"

## 3. D. 退休福利（2414–2423行）

- **规则变动**：**1993年1月1日**起强制要求**确认退休后健康福利负债的现值**（此前 GAAP 要求确认退休金，"却**不合理地忽略**企业未来必须承受的健康保险成本"）；将使许多公司在资产负债表上确认**一大笔负债**（净值减少），并使**后续年度利润缩水**。
- **作者的实践**：**购并时尽量避开背负高额退休金负债的公司**；伯克希尔员工逾万，但退休金负债与退休后负债成本**并不严重**。
  - **1982年差点犯错**：曾差点买下一家背负沉重退休金福利负债的公司，交易因"某些我们无法控制的因素"告吹；作者在1982年年报中写道"**两大页空白的跨页插图，可能最足以代表当年度告吹的交易**"；**后来另一家买主买下该公司，公司不久便倒闭关门，数千名员工的大笔健康福利承诺全部化为乌有**。
- **对行业行为的批评**：没有一家公司的CEO会向董事会提出**没有上限的**退休后健康福利计划，"即便没有专业的医学知识，也能知道越来越高的预期寿命以及福利支出将会把一家公司拖垮"；很多经理人"还是闭着眼睛，让公司通过内部自保的方式，投入这种永无止境的大坑洞"，**"就福利而言，没有上限的承诺所代表的就是没有上限的负债"**。
- **根因**：会计规则未要求将退休后健康成本呈现在账上（允许**现金发生制**，大大低估累计负债），管理层与会计师的态度是"**眼不见为净**"；**讽刺的是同一批管理层常批评国会对社保采取现金发生制**。
- **林肯的谜语**："如果一只狗连尾巴也算在内的话，总共有几条腿？"——"**四条腿，因为不论你是不是把尾巴当作一条腿，尾巴永远都是尾巴。**"→**"就算会计师愿意帮你证明尾巴也算是一条腿，你也不会因此多了一条腿。"**
- 注[1]="1992年。"

## 5. 主要疑点与保留项

1. **禧诗糖果"过去的78年"**：若以1921年创立、叙述时点为1999年计，78年吻合；但**本书未给出创立年份**，未外部核验。
2. **递延税两处差异**：第8章"减少7,100万"与第9章"减少约7,000万美元/7,300万美元"三处数字口径不一（复算均为7,200万），**登记不改**。
3. **本章全部数字**（12亿/6亿/76亿/64亿分层、11亿应缴税、2.24亿资本利得与7,600万税、1,336万股相关数据等）均为**作者自述，未核原财报**。
4. **作者的替代方案与 FASB 立场**属政策主张，仅作方法参考；**不得移植为"商誉一律不摊销"的会计主张**。
5. **1982年交易的细节与另一买主结局**为作者叙述，未核。
