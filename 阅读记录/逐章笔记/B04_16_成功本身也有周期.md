# B04 第16章 成功本身也有周期

来源：B04《周期》第16章，内部文件 `OEBPS/Text/text00021.html`，v2合并全文第 **1641–1721行**（81行，10,843字符；无脚注、无图）。正文逐段读完；本章所有历史数字与人物引文均保持`original_report_verified=false`。

## 1. 主张与四条机制链

本章的中心不是“赢家必输”，而是成功会改变人、价格、资金规模、竞争和组织，从而削弱原先的成功条件。

1. **人的成功周期**：成功→自我归因与过度自信→自我怀疑减少→安全边际、纪律和努力下降→跨出能力圈→失败概率上升。必要张力是“有足够自信做逆向判断，同时承认自己可能错”。
2. **策略与流行周期**：短期好业绩→资产变流行→资金、竞争者和机构涌入→价格上升、风险溢价下降、容量耗尽→风险调整后预期收益回归均值甚至更差。反向方向是表现差→资金退出与价格下跌，但**价格低不自动等于价值高或能够存活**。
3. **公司的成功周期**：创新/垄断与高利润→竞争、监管和自身惯性→自满、官僚、创新减弱、保护旧业务、能力圈外扩张→衰退；失败可能促成重组与再聚焦，但破产时旧股东可能损失全部股权。
4. **时机与运气周期**：早期进入尚未被发现、竞争少、定价便宜的市场，可贡献巨大业绩；后来者面对拥挤和价格上升，不能复制早期回报。因此复盘必须把技能、先发时机、流动性和竞争环境分开。

## 2. 可执行边界

- **不流行不是买入理由**：须另外证明资产质量、生存能力、价格—价值差与催化/耐心条件。
- **流行不是卖出理由**：须证明价格已透支、容量或风险补偿恶化；“流行程度与机会成反比”只作警报。
- **逢低买入不是无条件有效**：第1671行明确指出市场可能不反弹，越低越买会变成越买越低；仍须遵守预算、失效条件与现金底线。
- **策略有容量**：容量不仅是基金规模，还包括市场深度、可部署标的数量、冲击成本、拥挤交易、融资条件和退出通道。
- **企业复苏不等于旧股东获利**：经营恢复、债权回收和普通股价值必须分账。
- **一次成功不可外推**：成功可能来自不可复制机会、冒险或幸运；扩张到陌生领域前须重新证明能力。

## 3. 历史数字复算与疑点

### 《股票已死》后标普案例

书中给出1979-08-13标普约107点、2000年3月约1,527点：

- 价格倍数：`1527 / 107 = 14.271倍`，与“超过14倍”一致。
- 若把期间粗略取整为21年，价格CAGR为`14.271^(1/21)-1 = 13.49%`；若按约20.58年，约`13.79%`，与书中13.7%大体一致。
- 若含分红总财富倍数按“超过28倍”取28倍，21年CAGR为`17.20%`；按约20.58年为`17.58%`，与书中17.6%一致。书中“21年”显然是约数，精确年化需要具体起止日与总回报指数。

这些只是**内部算术一致性**，未核指数口径、分红再投资、起止日或原始数据。

### 其他疑点

1. 1999年成长股超越价值股近25个百分点、小盘/大盘轮动及可转债对冲业绩均无本章数据来源。
2. 施乐市场份额、1975年反垄断案、2000年4月支付1,000万美元终结SEC调查、重述财报与27亿美元融资等均为书内转述；其中SEC年份需原始资料核对。
3. “市场流行的东西肯定不会便宜”“每件明显正确的事其实都错”等为强调性绝对表述，不能直接成为筛选规则。
4. “失败孕育成功”对普通股可能完全不成立；破产重组可让企业存续而旧股东归零。
5. 彼得·考夫曼、斯文森、亨利·考夫曼、阿吉特·贾恩、巴菲特、亨利·菲利普斯和德摩斯梯尼等引文及转引链未核原文。
6. 作者的高收益债/不良债权早期经历、市场规模小于30亿美元和成功归因均为自述，不能推成当前产品授权。

## 4. 与框架的关系

- 与§13.6技能—运气分离衔接：增加**容量、拥挤、先发时机**三个归因项，防止把早期环境红利写成永久技能。
- 与§7主动资格衔接：策略即使历史有效，只要规模、竞争或成本改变，也要重新判断可复制性；历史净业绩不能覆盖当前容量问题。
- 与§8–§12企业研究衔接：高利润会吸引竞争与监管；公司成功后的官僚、创新停滞和越界并购应进入护城河反证与资本配置审查。
