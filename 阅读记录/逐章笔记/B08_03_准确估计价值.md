# B08 第3章：准确估计价值（277–338行）

## 2. 论证推进
- 投资方法的两分：基于**基本面（内在价值）** 与基于**价格行为**（技术分析、动量投资）。作者否定后者：动量投资遇到“无法永久持续的东西必将终结”；并批评日间交易者“10买11卖、24买25卖、39买40卖”，股价涨了30美元却只赚3美元。
- 基本面方法再分**价值投资**与**成长型投资**：
  - 价值投资＝估计当前内在价值并在价格低于它时买进；强调有形因素（收益、现金流、股利、硬资产、企业价值），极端形式如 net-net（市值低于流动资产减总负债）。
  - 成长型投资＝识别未来迅速增值的证券，重心在“潜力”而非当前属性。
- 作者的定义式区分：**真正的选择不是价值与成长，而是“当前价值”与“未来价值”**；价值投资者相信当前价值高于当前价格，成长型投资者相信未来价值的增长足以推高价格。成长型投资的平均成功率更低但成功时回报更高；作者自选价值投资——“**持续性比戏剧性更重要**”。
- **漂亮50的教训**（1968年纽约第一国民银行）：以“成长足够快、质量足够好，则股价高低不必考虑”为信条，名单包含IBM、施乐、柯达、宝丽来、默克、礼来、雅芳、可口可乐、菲利普·莫里斯、惠普、摩托罗拉、德州仪器、珀金埃尔默等；几十年后，柯达、宝丽来因技术变革基础业务锐减，IBM、施乐因行动迟缓被新兴竞争者蚕食。**长期增长的持续时间与准确预测能力都“不过如此”**。（点评者提醒：该组合若1968年买入并持有至今最终跑赢市场，但耗时数十年，且主要依赖菲利普·莫里斯的优异表现。）
- 价值投资的三个前提：①必须能**准确估计价值**（否则买到的可能是“高价特价股”，只能靠博傻脱身）；②必须**坚定持有**（“正确并不等于正确性能够被立即证实”；例：价值80美元、60美元买进后跌到50美元该怎么办）；③必须**是正确的**。
- 价格下跌时“越跌越爱”的行为学障碍：投资领域的“需求曲线”反了——价格上涨让人更加喜爱，价格下跌让人怀疑自己；“向下摊平”在人性上极难。损失面前人人不安，直到“也许市场才是对的”，这是一种**见底式思维**。
- 结论：在一个下跌的市场中获利需要三个基本要素——了解内在价值、足够自信地持股并继续买进、**并且确实是正确的**；“估价正确却不坚定地持有，用处不大；估价错误却坚定地持有，后果更糟”。

## 3. 案例

- 80/60/50美元的价格阶梯为**教学假设例**，非真实标的。

## 4. 公式/图表

## 5. 疑点
- “价值投资强调有形因素、无形因素比重较小”是作者对流派差异的概括，**不能当作估值的许可**：本项目估值仍按手册§10–§11（会计口径统一、正向模型＋反向预期＋安全边际）。
- 点评者关于漂亮50“最终跑赢市场”的说法基于1968年至其评述时点，**依赖幸存者与其认定口径**，不构成“高估值买入终将获胜”的许可。
